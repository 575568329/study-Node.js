# 学习进度更新器

## 概述

自动化学习进度记录，从会话上下文中提取学习成果并通过**后台子任务**更新核心文件。主进程不被阻塞，用户可继续学习。

## 📍 技能感知机制

**执行前必须先读取当前技能指针**：

1. 读取 `AGENTS.md` 中的"当前学习阶段"部分
2. 提取指针值：
   - `当前技能`: LangChain.js
   - `进度文件`: progress/langchain-progress.md
   - `会话目录`: sessions/langchain/
   - `项目目录`: projects/langchain-demo/
   - `Obsidian笔记`: study-notes/LangChain/
3. 后续所有文件操作基于这些指针路径动态解析

## 使用时机

用户说以下任一关键词时触发：
- "记录一下进度"、"更新进度"、"记录学习成果"、"记录今日学习"

**不要使用**：普通聊天、非学习相关的记录

## 核心流程（后台子任务模式）

```
用户触发 → 读取AGENTS.md指针 → 提取会话上下文 → 启动后台 Agent → 立即回复用户（可继续学习）
                                                            ↓
                                               后台 Agent 异步完成：
                                               1. 同步 Obsidian 笔记
                                               2. 完整性检查
                                               3. 更新 progress 文件
                                               4. 更新 session notes
                                               5. 更新 INDEX 文件
                                               6. 更新 AGENTS.md / README.md
```

### 执行步骤

**Step 1: 主进程提取上下文**（快速，不阻塞）

1. 读取 `AGENTS.md` 提取指针
2. 读取 `progress/{当前技能}-progress.md` 获取当前进度
3. 从会话上下文中提取本次学习的关键信息：
   - 新完成的主题（文件名、日期）
   - 学生问题和错误记录
   - 踩坑记录
   - 表现评估
4. 将以上信息打包

**Step 2: 启动后台 Agent**（不阻塞主进程）

使用 `Agent` 工具，设置 `run_in_background: true`，将 Step 1 提取的信息通过 prompt 传给子任务。prompt 必须包含：

```markdown

## 当前进度
[从 progress 文件读取的现有状态]

### 新完成主题
- 主题1: [描述]
- 主题2: [描述]

[问题列表和错误记录]

### 踩坑记录

[评估内容]

## 需要更新的文件清单
按以下顺序执行：

### 1. Obsidian 笔记（study-notes/LangChain/）
- 为每个新主题在 `01-知识点总结/` 创建笔记
- 笔记必须包含：学习日期、核心概念、代码示例、关键要点、常见错误
- 如有新的踩坑，更新 `03-易错点与陷阱/GLM-API踩坑.md`
- 更新速查表 `05-速查表/LangChain.js速查表.md`

### 2. 进度文件（progress/langchain-progress.md）
- 更新日期、进度百分比、学习天数
- 在"已掌握主题"表格添加新行
- 更新"踩坑记录"表格
- 更新"学习笔记"部分
- 更新"下次学习计划"

### 3. 会话记录（sessions/langchain/）
- 创建/更新当日 session-notes.md
- 更新 INDEX.md

### 4. 技能索引（study-notes/LangChain/INDEX.md）
- 添加新笔记链接
- 更新进度和下次学习内容

### 5. 根目录文件
- 更新 AGENTS.md 当前技能进度
- 更新 README.md 进度表
```

**Step 3: 立即回复用户**

后台 Agent 启动后，立即回复用户：

```

- [列出将更新的主题和文件]

```

**Step 4: 后台完成通知**

后台 Agent 完成后会自动通知，主进程确认即可。

## 信息提取清单

### 1. 学习成果
- **新增主题**: 识别本次学习的主题
- **进度变化**: 计算新进度百分比

### 2. 关键内容
- **学生问题**: 记录所有学生提出的问题（原文）
- **知识漏洞**: 识别的理解偏差
- **讲解方法**: 使用的教学方法

### 3. 错误内容提取（复习重点）⚠️
- **错误回答**: 学生的实际错误回答（原文）
- **误解分析**: 为什么会产生误解
- **纠正过程**: 如何纠正的
- **易错点**: 每个主题的易错知识点

## 进度计算

**动态计算**（不硬编码）：
1. 统计已掌握主题数量（已掌握主题表格行数）
2. 总数 = 已掌握 + 待学习（从待学习主题表格统计）
3. 百分比 = 已掌握 / 总数 × 100%

## 常见错误

- ❌ 使用硬编码路径 → ✅ 从 AGENTS.md 动态解析
- ❌ 缺少学生原始问题 → ✅ 记录所有问题（原文）
- ❌ 跳过完整性检查 → ✅ 后台任务必须检查 progress vs 笔记一致性
- ❌ 不记录错误 → ✅ 必须提取所有错误内容

- ✅ 更新所有核心文件（progress、session notes、INDEX、AGENTS.md、README.md）
