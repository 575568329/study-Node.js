# 课前复习与预测试技能

## 触发条件

用户说以下任一关键词时触发：
- "开始今日学习"、"开始学习"
- "开始今日的练习"

**不触发**：
- 普通聊天、代码调试、非学习相关对话

## 核心流程

```
触发 → 读取AGENTS.md指针 → 读取进度文件 → 生成课前小测 → 用户答题 → 判答 → 更新盲区状态 → 输出学习建议 → 进入新内容学习
```

## 理论依据

本技能基于以下经过研究验证的学习策略：

| 策略 | 效应量 | 来源 |
|------|--------|------|
| 提取练习（Retrieval Practice） | g = 0.50-0.70 | Rowland (2014), Adesope (2017) |
| 间隔重复（Spaced Repetition） | g = 0.54-0.74 | Cepeda (2008), Hattie (2021) |
| 预测试效应（Pretesting Effect） | +10-15% 保持率 | Richland, Kornell & Kao (2009) |
| 交错练习（Interleaving） | g = 0.42 | Brunmair & Richter (2019) |
| 过度校正效应（Hypercorrection） | 高信心错误最易纠正 | Metcalfe & Butterfield (2001) |

## 执行步骤

### Step 1: 读取上下文

并行读取以下文件：

1. **AGENTS.md** → 提取当前技能指针（当前技能、进度文件路径、会话目录等）
2. **progress/{当前技能}-progress.md** → 提取：
   - 待巩固复习清单（盲区列表）
   - 已掌握主题列表（标记为 `[x]` 的）
   - 上次复习时间（如果有）
   - 学习记录中的错题信息
3. **sessions/{当前技能}/INDEX.md** → 最近一次会话的主题
4. **AGENTS.md 学习路线** → 确定关联技能（前序/后续技能）

**技能关联规则**：

```
Node.js → TypeScript → Vue3+TS → React+TS → Next.js
              ↑              ↑
              └── 直接关联 ──┘
```

- 当前技能的**前一个**和**后一个**为直接关联
- 其余为间接关联

### Step 2: 生成课前小测

**总题量：5-8 题，总用时 5-10 分钟**

题目分配：

| 题型 | 数量 | 来源 | 目的 |
|------|------|------|------|
| **预测试题** | 2-3 题 | 今日将要学的新主题 | 激活知识结构（即使全错也有价值） |
| **盲区题** | 1-2 题 | 上次标记的待巩固内容 | 验证薄弱点是否解决 |
| **随机题** | 1 题 | 已掌握内容中随机抽取 | 发现隐性遗忘 |
| **跨技能题** | 1 题 | 直接关联的旧技能 | 跨领域巩固 |

**题目设计原则**：

1. **预测试题**：
   - 不要求正确答案，目的是"先尝试"
   - 出题方式："我们今天要学 [新概念]，你对它有什么了解？试着回答以下问题："
   - 即使答"不知道"也算有效，记录为"预测试零基础"

2. **盲区题**：
   - 从待巩固清单中优先选**优先级最高**的
   - 题型以代码题为主（写代码 > 选答案）
   - 必须与原始盲区直接相关

3. **随机题**：
   - 从已掌握列表（`[x]` 标记）中随机选一个主题
   - 避免选最近 3 次复习中已抽查过的主题
   - 题型：代码题或概念解释题

4. **跨技能题**：
   - 只出**直接关联**技能的题
   - 优先选择新旧技能的**交叉点**（如学 Vue3 时考 TS 泛型在组件 Props 中的应用）
   - 如果当前是第一个技能（Node.js），则跳过跨技能题

**出题格式**：

```
📋 课前小测（预计 5-10 分钟）

**Part 1: 预测试**（今天要学的新内容，答错没关系）
Q1: [新概念相关问题]
Q2: [新概念相关问题]

**Part 2: 巩固检查**（上次的薄弱点）
Q3: [盲区题]
Q4: [盲区题]（如果有多个盲区）

**Part 3: 随机抽查**（验证是否遗忘）
Q5: [已掌握内容的随机题]

**Part 4: 跨技能联动**（关联旧知识）
Q6: [关联技能题]
```

### Step 3: 判答与分析

逐题判答，对每题记录：

```
| 题号 | 类型 | 结果 | 置信度 | 备注 |
|------|------|------|--------|------|
| Q1 | 预测试 | ❌ | 低 | 完全不了解（正常） |
| Q3 | 盲区 | ✅ | 高 | 已掌握，可移出清单 |
| Q5 | 随机 | ⚠️ | 中 | 部分遗忘，需关注 |
```

**置信度判定规则**：
- **高信心正确**：回答流畅且准确 → 标记为"已验证"
- **低信心正确**：答对了但犹豫或表述模糊 → 标记为"待验证"
- **高信心错误**（Hypercorrection 重点）：非常确信但答错 → **最高优先级盲区**
- **低信心错误**：不确定且答错 → 标记为新盲区

**关键：高信心错误是复习金矿**

当检测到高信心错误时：
1. 明确告知用户："这个知识点你之前很确信，但实际上理解有偏差"
2. 立即分析错误根源
3. 加入盲区清单并标记为 **P0 优先级**

### Step 4: 更新盲区状态

根据判答结果更新 `progress/{当前技能}-progress.md` 中的待巩固清单：

**状态转换规则**：

```
盲区题答对（高信心） → 移出待巩固清单，标记为"已验证 MM-DD"
盲区题答对（低信心） → 保留在清单，标记为"待验证"
盲区题答错 → 保留，增加复习次数计数
随机题答错 → 新增为盲区，加入待巩固清单
随机题答对 → 无操作
跨技能题答错 → 在对应技能的待巩固清单中新增（如果有权限）
预测试题 → 不影响盲区状态
```

### Step 5: 计算间隔复习时间

根据 Cepeda (2008) 的公式（最佳间隔 = 目标保持时长的 10%-40%）：

```
下次复习时间 = 当前日期 + 计算间隔

计算规则：
- 刚学的概念：1-3 天后复习（目标保持 7 天）
- 已验证的概念：7 天后复习（目标保持 30 天）
- 多次验证的概念：21 天后复习（目标保持 60 天）
- 跨技能概念：14 天后复习
```

在 `progress/{当前技能}-progress.md` 中更新下次复习日期。

### Step 6: 输出学习建议

在课前小测结束后，输出简要建议：

```
📊 课前小测总结

✅ 已巩固：[列出答对的盲区题]
⚠️ 仍需关注：[列出仍答错的盲区]
🔍 新发现：[列出随机/跨技能题暴露的新问题]

💡 今日学习建议：
- [基于预测试结果的建议：哪些新概念需要重点关注]
- [基于盲区状态的建议：学习新内容时注意与哪些旧知识关联]

📝 已更新：
- 待巩固清单：+X 新增 / -Y 移出 / Z 保留
- 下次复习重点：[列出]
```

然后自然过渡到新内容学习（苏格拉底式教学开始）。

## 特殊场景处理

### 场景1: 首次学习（无进度文件）

- 跳过盲区题和随机题
- 只出预测试题（2-3 题）+ 跨技能题（如果有前序技能）
- 不更新任何文件

### 场景2: 进度 100% 的技能（如 TypeScript）

- 无预测试题（没有新内容要学）
- 重点出盲区题 + 随机题
- 跨技能题比例增加

### 场景3: 间隔时间未到

如果上次复习时间距今 < 计算间隔的一半：
- 减少盲区题数量
- 增加预测试题和跨技能题比例
- 提示"距离上次复习时间较短，今天以新内容为主"

### 场景4: 无待巩固内容

- 盲区题部分跳过
- 增加随机题至 2 题
- 输出"上次学习内容已全部掌握，今天专注新内容"

## 注意事项

- **不要出太难的题**：课前小测的目的是激活知识，不是打击信心
- **预测试题的答错是正常的**：明确告知用户"这些题本来就是让你尝试的"
- **不要拖延太久**：总时间控制在 5-10 分钟，不要让复习挤占学习时间
- **自然过渡**：小测结束后不要生硬切换，用预测试中暴露的好奇心自然引入新内容
- **苏格拉底式衔接**：预测试中的错误可以直接作为新内容讲解的起点

## 文件更新清单

课后小测完成后，需要更新的文件：

| 文件 | 更新内容 |
|------|---------|
| `progress/{当前技能}-progress.md` | 更新待巩固清单状态、复习日期 |
| `sessions/{当前技能}/{日期}/session-notes.md` | 在会话开头记录课前小测结果 |
