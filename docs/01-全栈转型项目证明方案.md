# 全栈转型项目证明方案

更新时间：2026-05-07

## 目标

把已有学习成果收束成一个能支撑求职的全栈项目证明体系。

核心不是继续学习更多技术，而是证明：

1. 能做完整全栈 AI 应用。
2. 能解释每个技术选择。
3. 面试追问时能讲清楚实现、边界和取舍。

## 主定位

**全栈工程师｜Node.js / React / Next.js｜AI 应用方向**

优势来源：

- 5-6 年复杂前端业务交付经验。
- Vue2 / Vue3 / React / TypeScript 基础。
- Node.js / Next.js API Route 全栈补强。
- RAG、AI SDK、LangChain、LangGraph 学习储备。
- 真实工作项目：教育出海国际化、GIS 可视化、IoT 实时数据。
