### 额外知识点
- toRefs 只认 reactive 对象，ref.value 内部是 reactive 可用但不推荐
- ref 包对象不需要解构，直接 .value.name 访问
- Vue DevTools 是浏览器插件，Vue 应用的调试工具
- Gemini CLI 工具（gemini-cli.mjs）已创建，用智谱 API 替代浏览器方式
