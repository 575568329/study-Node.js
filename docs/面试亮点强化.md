# 面试亮点强化学习笔记

## 1. AI 驱动的研发效能（核心杀手锏）
**亮点描述**：从手写代码转向“提示工程驱动”的开发模式，提升 100% 开发效率。
*   **核心工具链**：Gemini CLI (底层辅助) -> Claude Code (架构与逻辑) -> AI 自动化测试方案。
*   **面试话术**：
    > “我目前已经实现了 95% 以上的代码由 AI 生成。我不仅是使用者，更是 AI 开发流的编排者。我通过编写高质量的设计文档和结构化 Prompt，指导 Claude Code 进行复杂业务逻辑重构，并将 Bug 修复效率提升了 80%。”
*   **进阶思考**：如何利用 AI 进行 **自动化测试（PageAgent）**？（利用 AI 模拟用户点击，验证 UI 布局是否在多语言下崩坏）。

## 2. 复杂 GIS 数据交互与渲染优化
**亮点描述**：处理千万级利润项目的海量地理数据。
*   **技术点**：省市县分级加载、OpenLayers 二次封装、图层加载时序控制。
*   **面试话术**：
    > “在处理三维地质灾害预警系统时，核心难点在于‘大规模点位渲染’与‘三维模型交互’的平衡。我通过分级加载策略减少了首屏 60% 的数据请求，并通过时序控制优化了地图底图与业务图层的覆盖关系，保证了在复杂交互下的帧率稳定。”

## 3. 异构系统下的多语言适配（i18n）
**亮点描述**：在 Vue2 + Angular 混用的“屎山”中优雅实现国际化。
*   **技术点**：Latex + 图片保底、MathJax 异步渲染、i18n 动态映射。
*   **面试话术**：
    > “我负责了教育出海项目的多语言底层适配。面对 LaTeX 这种复杂的数学公式，我设计了‘图片占位+Latex 异步渲染’的双保险方案。同时，针对葡语等长文本导致的 UI 崩坏，我正在研究基于 CSS 变量和弹性布局的通用适配框架。”

## 4. 工业级软件工程规范
**亮点描述**：深度参与讯飞标准的开发全生命周期。
*   **关键词**：设计评审、代码审查（CR）、A/B 测试、上线 Checklist。
*   **面试话术**：
    > “我深刻理解规范流程对于交付质量的价值。在讯飞项目中，我严格执行‘设计评审前置’，在开发前规避潜在风险。同时，我关注代码覆盖率和灰度发布指标，确保每一次发版都具备可追溯性和安全性。”
