# 统一复习矩阵

更新时间：2026-05-07

## 目标

把 `Node / React / Vue / Next / AI / 后端` 按三个层级统一整理：

1. `必问`：面试高频，必须能脱口而出。
2. `需精进`：知道原理，但还要继续练表达和边界。
3. `项目关联`：能和当前项目、简历、追问材料接起来。
