整理学习笔记时,用户要求每个技能/知识点都要有一句话「记忆锚点」,放在 INDEX.md 顶部(翻笔记第一眼能看到),用于快速背诵、回忆技能骨架。

**Why:** 用户是实践 + 深度思考型,习惯用高度浓缩的一句话锚定一个技能的骨架,再展开细节。本会话内反复强调过(要一句话概括 → 要 Skill 独立成篇 → 要记忆锚点)。

**How to apply:** 帮用户整理任何技能笔记时,主动在 INDEX.md(及速查表)顶部写一句 `> 🧠 记忆锚点:...`,一句话覆盖:是什么 + 核心主线 + 关键区别点;先给文案让用户确认再写入。老技能补锚点时先读其 INDEX 再起草,避免凭空写偏。关联 [[feedback-teaching-style]](先讲语法格式)。
