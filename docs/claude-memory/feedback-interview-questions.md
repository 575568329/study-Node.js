每次学习会话结束时，整理 2-3 道本次学习相关的面试题：
1. 存到 `study-notes/{当前技能}/04-面试题/` 目录下
2. 在对话中告知用户整理了哪些面试题
3. 格式：问题 + 参考答案（简洁版，1-3句话）

**Why:** 用户希望边学边积累面试题，05-20 面试冲刺周时有现成题库可用
**How to apply:** 每次会话结束前（用户说"结束"/"提交"时），自动整理并保存面试题
