教学和复习方法论已通过学术研究验证（2026-03-30），所有方法有效。

**验证结论（有研究支持）**：
- 理解检查题（Formative Assessment）：effect size 0.4-0.7，证据极强
- 错误驱动教学（Productive Failure）：160+实验，效果为传统方法 3 倍
- 提取练习 vs 重读笔记：g = 0.50-0.70，1周后正确率 67% vs 49%
- 间隔重复：g = 0.54-0.74，最佳间隔 = 目标保持时长的 10%-40%
- 交错练习（跨技能）：g = 0.42，数学类 d = 0.83
- 预测试效应：即使全答错，后续学习效果也高 10-15%
- 苏格拉底式教学：多项研究证实提升批判性思维

**已揭穿**：Learning Pyramid（学习金字塔百分比）是伪科学

**How to apply:** 教学方法有科学背书，可以放心使用。复习机制基于间隔重复公式，每次会话前自动执行课前小测。
