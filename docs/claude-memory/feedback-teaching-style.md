教学时先讲语法格式再讲例子。不相关的概念要明确告知"和XX无关"，避免学生强行找关联。

**Why:** 用户反馈：(1) 讲 useReducer 时不理解 `useReducer(reducer, [])` 参数含义，因为没先讲语法 (2) useContext 和 useReducer 放一起讲导致困惑，以为必须关联使用

**How to apply:** 每个新知识点：先说语法 → 再讲例子 → 最后说和前面学过的什么有关/无关。无关联的概念明确声明"这个和XX没有关联"。
