## 🔧 推荐插件

### 核心插件

1. **Dataview** ⭐⭐⭐
   - 用途: 从笔记中查询数据
   - 安装: 设置 → 社区插件 → 浏览 → 搜索 "Dataview"
   - 使用: 可以用SQL-like语法查询笔记

2. **Calendar** 📅
   - 用途: 按日期组织笔记
   - 安装: 设置 → 社区插件 → 浏览 → 搜索 "Calendar"
   - 使用: 点击日期创建当日学习笔记

3. **Tag Wrangler** 🏷️
   - 用途: 管理标签
   - 安装: 设置 → 社区插件 → 浏览 → 搜索 "Tag Wrangler"
   - 使用: 快速重命名、合并标签

4. **Excalidraw** ✏️
   - 用途: 绘制知识图谱
   - 安装: 设置 → 社区插件 → 浏览 → 搜索 "Excalidraw"
   - 使用: 画流程图、架构图

## 📝 使用技巧

### 1. 双向链接 [[]]

**创建链接**:
```markdown
# 我在学习 [[Promise基础]]
# 相关概念: [[async/await]] 和 [[Event Loop]]
```

**查看反向链接**:
- 点击笔记标题旁边的链接图标
- 查看"反向链接"面板

### 2. 标签系统 #

**使用标签**:
```markdown
---
tags:
  - 重要
  - 概念
  - 需复习
---
```

**搜索标签**:
- `#重要` - 查找所有重要笔记
- `#易错点` - 查找易错点
- `#已掌握` - 查找已掌握的知识

### 3. 嵌入笔记 ^embed

**嵌入其他笔记**:
```markdown
![[CommonJS vs ES6模块化#核心区别]]
```

### 4. 代码块语法高亮

```javascript
// 记得指定语言
const fs = require('fs');
```

支持的语言:
- `javascript` / `js`
- `json`
- `bash` / `sh`
- `sql`
- `http`

### 5. 任务列表 - [ ]

```markdown
- [ ] 待完成
- [x] 已完成
- [/] 进行中
```

### 6. 使用模板

**安装 Templates 插件**:
1. 设置 → 社区插件 → 浏览 → 搜索 "Templates"
2. 启用后，左侧会出现模板图标
3. 设置模板文件夹: `templates/`
4. 使用: 命令面板 (Ctrl/Cmd + P) → "Insert template"

## 📊 使用 Dataview 查询

### 查询所有易错点

```dataview
LIST
FROM "03-易错点与陷阱"
WHERE contains(tags, "易错点")
SORT file.ctime DESC
```

### 查询未掌握的知识

```dataview
TASK
WHERE !completed
FROM "01-知识点总结"
```

### 查询本周学习的笔记

```dataview
LIST
WHERE file.ctime >= date(today) - dur(7 days)
SORT file.ctime DESC
```

## 💡 最佳实践

### 学习时
1. 每学一个知识点，创建对应笔记
2. 使用 `[[双链接]]` 关联相关概念
3. 代码示例放到 `02-代码示例/`
4. 遇到错误记录到 `03-易错点与陷阱/`

### 复习时
1. 查看 [[03-易错点与陷阱]]
2. 使用图谱视图查看知识关联
3. 用 Dataview 查询未掌握的知识

### 记笔记时
1. 使用模板保持一致性
2. 添加标签便于查找
3. 用自己的话解释概念
4. 添加可运行的代码示例

## 🎓 学习工作流

### 每日学习流程

1. **开始前**
   - 打开 [[00-学习导航/README]]
   - 查看 [[07-学习计划/学习计划]]
   - 回顾 [[03-易错点与陷阱]]

2. **学习中**
   - 创建新笔记使用 `templates/知识点模板`
   - 记录到对应文件夹
   - 代码放到 `02-代码示例/`
   - 遇到错误记录到 `03-易错点与陷阱/`

3. **学习后**
   - 更新 [[07-学习计划/学习计划]]
   - 添加双链接关联概念
   - 更新今日学习记录

## 🆘 常见问题

### Q: 笔记太多了怎么办？
A: 使用标签和文件夹分类，用Dataview查询

### Q: 如何快速查找某个概念？
A: 使用 `Ctrl + Shift + F` 全局搜索

### Q: 代码块不显示语法高亮？
A: 确保在代码块后指定语言：\`\`\`javascript

### Q: 如何导出笔记？
A: 文件 → 导出 → 选择格式（PDF/HTML）
