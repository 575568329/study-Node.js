## 🗺️ 知识图谱

### 核心概念关系

```
Node.js基础
├─ 模块化系统
│  ├─ CommonJS (require/module.exports)
│  └─ ES6模块 (import/export)
├─ 异步编程
│  ├─ Promise
│  ├─ async/await
│  └─ Event Loop
└─ 全局对象
   ├─ __dirname/__filename
   └─ process对象

内置模块
├─ fs (文件系统)
├─ path (路径处理)
├─ http (Web服务器)
└─ events (事件发射器)

Web框架
└─ Express
   ├─ 路由
   ├─ 中间件
   └─ RESTful API
```
