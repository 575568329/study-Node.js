## 🎯 核心概念

### 1. PM2 进程管理
Node.js 的进程管理工具，解决 `node server.js` 的两个致命问题：
- **进程崩溃 = 服务挂掉** → PM2 自动重启
- **关终端 = 服务停止** → PM2 后台运行

**常用命令**：
```bash
pm2 start server.js --name movie-api  # 启动
pm2 list                            # 查看状态
pm2 restart server                   # 重启
pm2 stop server                      # 停止
pm2 logs server --lines 5            # 查看日志
pm2 show server                      # 查看详情（含日志文件路径）
```

**PM2 原理**：拦截进程的标准输出流（stdout），同时输出到终端和写入日志文件。

### 2. 环境变量安全
- `.env` — 存真实密码和密钥，**不提交到 Git**（.gitignore 排除）
- `.env.example` — 模板文件，用占位符（`your_password`），**提交到 Git**
- 其他人克隆代码后：复制 `.env.example` → 重命名为 `.env` → 填入自己的值

### 3. Nginx 反向代理
```
用户浏览器 → http://域名:80 → Nginx → 转发到 → localhost:3001
```
- 用户只看到80端口，不知道后端是什么技术
- Nginx 还能处理：静态文件、HTTPS证书、负载均衡

### 4. 完整部署流程
1. **购买云服务器**（阿里云/腾讯云，Ubuntu 系统）
2. **开放端口**：22(SSH)、80(HTTP)、443(HTTPS)、3306(MySQL)
3. **安装环境**：Node.js、MySQL、Nginx、PM2
4. **上传代码**：Git 克隆（推荐）
5. **配置环境变量**：创建 `.env`，填入生产密码
6. **安装依赖 + 启动**：`npm install` → `pm2 start server.js`
7. **配置 Nginx**：反向代理到 Node.js 端口
8. **测试接口**

## ❌ 常见错误与纠正（复习重点）⚠️

### 错误1：直接 node 启动生产服务
- **错误**: 在服务器上用 `node server.js`，关终端就挂了
- **正确**: 用 `pm2 start`，后台运行 + 自动重启

### 错误2：.env 提交到 Git
- **错误**: 数据库密码和 JWT 密钥暴露在 GitHub
- **正确**: .gitignore 排除 .env，用 .env.example 做模板

### 易错点总结
1. PM2 的 `--name` 参数很重要，方便后续管理多个服务
2. 生产环境的 JWT_SECRET 至少32位随机字符串
3. .env 和 .env.example 要同步维护（新增变量时两个都要更新）
