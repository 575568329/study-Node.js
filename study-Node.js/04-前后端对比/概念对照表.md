# 前后端概念对照表

> **基于6年前端经验的对比学习**

---

## 📦 模块系统

| 前端 | 后端Node.js | 说明 |
|------|------------|------|
| `import` | `require()` | 不同模块系统 |
| `export` | `module.exports` | 导出方式不同 |
| `import { fn } from './mod'` | `const { fn } = require('./mod')` | 解构导入 |
| `import mod from './mod'` | `const mod = require('./mod')` | 默认导入 |
| webpack处理模块 | Node.js自己处理 | 模块加载机制不同 |
| `.js`就是ES6模块 | 可能是CommonJS | 取决于package.json |

## 🌐 HTTP通信

| 前端 | 后端Node.js | 说明 |
|------|------------|------|
| `axios.get('/api/users')` | `http.createServer()` | 前端调用，后端创建 |
| `.then(res => ...)` | `res.end(data)` | 前端接收，后端返回 |
| `axios.post('/api/login', data)` | 监听`req`的`data`事件 | POST数据传输 |
| `res.data` | `JSON.parse(body)` | 前端自动解析，后端手动 |
| `res.status` | `res.statusCode` | 状态码访问方式 |
| `res.headers` | `res.setHeader()` | 响应头设置 |

**完整示例**:

```javascript
// 前端
axios.post('http://localhost:3000/api/login', {
  username: 'admin',
  password: '123456'
})
.then(res => {
  console.log(res.data);  // { code: 200, token: 'xxx' }
  console.log(res.status);  // 200
});

// 后端
const http = require('http');
const server = http.createServer((req, res) => {
  if (req.method === 'POST' && req.url === '/api/login') {
    let body = '';
    req.on('data', chunk => body += chunk);
    req.on('end', () => {
      const data = JSON.parse(body);  // { username, password }
      res.setHeader('Content-Type', 'application/json');
      res.statusCode = 200;
      res.end(JSON.stringify({ code: 200, token: 'xxx' }));
    });
  }
});
```

## ⏱️ 异步编程

| 前端 | 后端Node.js | 说明 |
|------|------------|------|
| `fetch().then()` | `fs.readFile().then()` | Promise用法相同 |
| `async/await` | `async/await` | 语法完全相同 |
| `Promise.all()` | `Promise.all()` | 并行执行相同 |
| `setTimeout()` | `setTimeout()` | 定时器相同 |
| Event Loop | Event Loop | 机制相同，环境不同 |

**关键理解**:
- 前端和后端的异步编程**语法完全一样**
- 区别在于**异步操作的类型**（网络请求 vs 文件操作）

## 📁 文件操作

| 前端 | 后端Node.js | 说明 |
|------|------------|------|
| ❌ 不能直接操作文件 | ✅ `fs.readFile()` | 后端特权 |
| `File API`（有限） | `fs`模块（强大） | 能力天壤之别 |
| 上传文件到服务器 | 保存文件到磁盘 | 前端发送，后端保存 |
| `Blob` | `Buffer` | 二进制数据处理 |

**示例对比**:

```javascript
// 前端 - 只能读取用户选择的文件
const file = document.querySelector('input[type="file"]').files[0];
const reader = new FileReader();
reader.onload = (e) => console.log(e.target.result);
reader.readAsText(file);

// 后端 - 可以读取任意文件
const fs = require('fs').promises;
const data = await fs.readFile('./config.json', 'utf-8');
```

## 🛣️ 路由

| 前端 | 后端Node.js | 说明 |
|------|------------|------|
| Vue Router / React Router | `if (url === '/api/users')` | 前端框架路由 vs 手动判断 |
| `/user/:id` | `url.split('/')[3]` | 动态路由处理 |
| 路由跳转 | 返回不同数据 | 导航 vs 数据响应 |
| `router.push('/path')` | `res.redirect('/path')` | 重定向 |

**示例对比**:

```javascript
// 前端（Vue Router）
<router-link to="/user/123">用户详情</router-link>
{
  path: '/user/:id',
  component: UserDetail
}

// 后端（手动路由）
if (req.url.startsWith('/user/')) {
  const id = req.url.split('/')[2];  // '123'
  // 返回用户数据
}
```

## 🔐 安全性

| 前端 | 后端Node.js | 说明 |
|------|------------|------|
| 没有安全验证 | 必须验证所有请求 | 前端不可信 |
| XSS防护（转义HTML） | 输入验证、数据验证 | 双层防护 |
| CSRF Token | CSRF Token | 配合使用 |
| 隐藏敏感信息 | 加密存储（bcrypt） | 密码处理 |
| localStorage | httpOnly cookie | Token存储 |

**关键原则**:
- **永远不要信任前端的数据**
- 后端必须验证所有请求
- 敏感操作必须在后端进行

## 🎯 学习建议

### 作为前端开发者学习Node.js的优势

1. ✅ **JavaScript语法相同** - 无需学习新语言
2. ✅ **异步编程经验** - Promise、async/await已经熟悉
3. ✅ **包管理工具** - npm已经用过
4. ✅ **调试技巧** - 浏览器调试经验可以复用

### 需要特别注意的

1. ⚠️ **模块系统不同** - CommonJS vs ES6模块
2. ⚠️ **文件操作权限** - 后端可以操作任意文件
3. ⚠️ **安全性思维** - 后端必须验证所有请求
4. ⚠️ **错误处理** - 后端错误会影响所有用户

### 学习策略

1. **对比学习** - 用前端知识类比后端概念
2. **实践优先** - 写代码比看书更有效
3. **关注差异** - 重点学习后端特有的概念
4. **安全意识** - 时刻记住后端安全的责任
