## 🔄 工作流程

### 每日学习流程

1. **复习** (15分钟)
   - 查看 [[03-易错点与陷阱]]
   - 回顾昨天学的内容

2. **学习新知识** (1.5-2小时)
   - 看视频课程
   - 记笔记到 [[01-知识点总结]]
   - 代码练习

3. **实战练习** (30分钟)
   - 写代码验证理解
   - 记录到 [[02-代码示例]]

4. **总结整理** (15分钟)
   - 更新 [[07-学习计划/学习计划]]
   - 更新进度追踪器
   - Git提交并推送

### AI导师协作

**学习前**:
1. 打开 Claude Code
2. AI自动读取学习进度
3. AI询问今天的学习计划

**学习中**:
1. AI采用苏格拉底式教学
2. 先问理解，再讲解
3. 提供代码示例
4. 验证代码正确性

**学习后**:
1. AI更新学习记录
2. AI识别知识漏洞
3. AI建议下一步学习
