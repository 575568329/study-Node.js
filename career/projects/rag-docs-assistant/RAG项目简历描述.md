# RAG项目简历描述

更新时间：2026-05-07

## 项目定位

智能知识管理平台 / RAG 文档问答系统

面向个人或小团队的专业资料检索场景，支持多格式文档入库、向量检索、流式问答、来源引用和知识图谱展示。

## 技术栈

`Next.js`、`React`、`TypeScript`、`AI SDK`、`GLM-4-flash`、`embedding-3`、`pdfjs-dist`、`mammoth`、`exceljs`、`FileStore / ChromaDB`、`graphology`

## 简历 Bullet

1. 基于 Next.js App Router 搭建 AI 知识管理工作台，支持知识库管理、文档上传、RAG 问答和知识图谱三个工作区联动。
2. 实现 `.txt`、`.md`、`.pdf`、`.docx`、`.xlsx` 多格式文档解析链路，完成切片、批量 Embedding 和本地向量持久化。
3. 设计单知识库 / 全部知识库两种检索模式，并结合向量检索、关键词检索和 RRF 融合排序提升召回效果。
4. 使用 AI SDK 实现流式问答，回答结果返回 `sources`、文件名、章节和相关性分数，支持来源追溯与调试排查。
5. 抽象 `FileStore / ChromaStore` 向量存储层，兼顾个人演示场景和后续向更高规模向量库演进的能力。
6. 采用异步方式抽取文档实体和关系并写入知识图谱，保证图谱增强能力不阻塞文档上传和问答主链路。

## 简历使用边界

- 可以写：RAG 闭环、文档解析、向量检索、流式回答、来源追溯、图谱增强
- 不要写：生产级权限系统、完整对话持久化、大规模高并发向量检索、完整 GraphRAG

## 可压缩版本

如果简历篇幅紧，可以压成 3 条：

1. 基于 Next.js + TypeScript 实现 AI 知识管理平台，覆盖知识库管理、文档上传、RAG 问答和知识图谱展示。
2. 支持多格式文档解析、切片、批量 Embedding 和混合检索，并通过 `sources` 返回来源引用提升可追溯性。
3. 抽象本地 FileStore / ChromaDB 向量存储，并通过异步图谱抽取保证入库主链路和增强链路解耦。
