# 智学网 - Java 后端 i18n 改造(面试讲稿)

## 📌 简历 bullet(原文)

> 用 Claude Code / Cursor 完成 Java 后端多语言改造(vibe coding 落地后端,体现全栈):设计 @I18nField / @I18nMethod 注解 + I18nAspect 切面,对资源加工返回对象按 prefix / key / fieldName 三种模式自动国际化(覆盖选项值、环节名、学段学科);统一异常处理器按 Header(locale / localeWorkShop / isInWorkShop)决策语言——工作室内用工作室语言、外用全局语言;翻译先查完整匹配、部分翻译(含中文)回退原文保可用。

## 🎯 为什么做(背景)

智学网澳门出海,资源加工平台支持简/繁/英/葡 4 语言。**前端双语言(工作室语言/页面语言)已落地(resolveBizLocale)**,但**后端 Java 返回的数据对象(选项值、环节名、学段学科)+ 异常消息还是中文**——前端翻完、后端返回中文,半中半外。所以后端也要 i18n,且要和前端双语言决策**一脉相承**。

## 🧩 技术方案

### 1. 注解 + 切面(声明式国际化)
- `@I18nField`(字段注解)+ `@I18nMethod`(方法注解),在 `crowdsourced-new-service-api` 定义。
- `I18nAspect` 切面(`crowdsourced-new-web`),拦截返回值,自动处理带 `@I18nField` 的字段 + Phase/Subject(学段学科)。
- **为什么注解+切面**:声明式(标 `@I18nField` 自动翻),不改业务逻辑,**关注点分离**(业务码不掺 i18n)。

### 2. @I18nField 三种模式(覆盖不同返回结构)
| 模式 | 场景 | 例子 |
|---|---|---|
| **key**(固定键) | 字段值对应固定翻译 | `@I18nField(key="i18n.ChoiceItem.36")` 选项 id→翻译 |
| **prefix**(前缀) | 字典类,按值查 | `@I18nField(prefix="i18n.dict.TaskType")` 环节名→字典查 |
| **fieldName**(嵌套) | 字段是对象,翻对象内字段 | `@I18nField(fieldName="name", prefix="i18n.ChoiceItemCategory")` category.name |

### 3. 异常国际化统一处理(双语言决策)
- 前端 Header 传三参:`locale`(全局)/ `localeWorkShop`(工作室)/ `isInWorkShop`(1 内 / 2 外)。
- `CustomExceptionResolver` 统一异常处理器:拦 `ELPBizException` / `IllegalArgumentException`,调 `translateMessageIfNeeded`。
- **决策**:`isInWorkShop=1`(工作室)用 `localeWorkShop`,`=2`(外)用 `locale`——和前端 `resolveBizLocale` 双语言**一脉相承**。
- 只翻译非 `zh_CN`(大陆原流程不动)。

### 4. 翻译回退(I18nUtilsExt,保可用)
- `translateContentIfFullMatchExists`:先查完整翻译资源 → 有则用;无则原翻译;翻译**含中文(部分翻译)回退原文**。
- **为什么回退**:部分翻译(半中半外)比原文更难看,回退保可用。
