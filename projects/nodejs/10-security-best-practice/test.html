🛡️ 安全最佳实践演示

F.9 Security Best Practices - Rate Limiting, Helmet, Data Sanitization, Log Security

1️⃣ Helmet - HTTP安全头

原理：Helmet自动添加15+个HTTP安全头，防止XSS、点击劫持等攻击
检查：打开浏览器开发者工具 → Network → 查看响应头

2️⃣ Rate Limiting - 速率限制（登录接口）

限制：5次/分钟（成功不计入，失败计入）
目的：防止暴力破解密码攻击
测试账号：alice / hashed_password_123
失败次数：0/5

3️⃣ Rate Limiting - 全局限制

限制：100次/分钟
目的：防止DDoS攻击
请求次数：0/100

4️⃣ 数据脱敏 - 不返回敏感信息

敏感字段：password（密码）、phone（手机号）
脱敏策略：password不返回，phone只显示前3后4位（138****8000）

5️⃣ 日志安全 - 不记录敏感信息

对比实验：查看服务器控制台
不安全：日志中包含password（危险）
安全：日志中不包含password（删除后记录）
⚠️ 查看服务器控制台：对比两种日志方式的区别
