# TS.2 接口与类型别名

> 学习日期: 2026-03-30 | 置信度: 高

---

## interface — 定义对象形状

```ts
interface User {
  name: string
  age?: number           // 可选属性
  readonly id: number    // 只读属性
}
```

类似 Vue2 的 props 验证，但更强大。

### 继承

```ts
interface Animal { name: string }
interface Dog extends Animal { breed: string }
```

## type — 类型别名

给类型起名字，方便复用：

```ts
type Callback = (data: string) => void

// 使用
let back: Callback = (data) => { console.log(data) }
```

## interface vs type 区别

### type 能做，interface 做不到

```ts
type Status = "active" | "inactive"   // 联合类型
type ID = number                       // 基本别名
type Point = [number, number]          // 元组
```

### interface 能做，type 做不到

```ts
// 声明合并 —— 同名自动合并
interface User { name: string }
interface User { age: number }
// 最终 User = { name: string; age: number }
```

### 继承方式不同

```ts
// interface 用 extends
interface Dog extends Animal { breed: string }

// type 用 &（交叉类型）
type Dog2 = Animal2 & { breed: string }
```

## 选择原则

| 场景 | 选谁 |
|------|------|
| 定义对象形状 | interface |
| 联合类型、元组、基本别名 | type |
| 需要声明合并 | interface |
| 其他 | 都行，团队统一 |

## 索引签名

动态 key 的对象：

```ts
interface ScoreMap {
  [key: string]: number
}
```

## 可选属性与只读

```ts
interface User {
  readonly id: number    // 创建后不能改
  name: string
  age?: number           // 可以不传
}
```
