# TS.1 基础类型与类型注解

> 学习日期: 2026-03-30 | 置信度: 高

---

## 类型注解

TypeScript 在变量后加 `: 类型` 标注：

```ts
let name: string = "张三"
let age: number = 25
let isDone: boolean = true
```

## 类型推断

TypeScript 会根据初始值自动推断类型，不需要每个变量都写注解：

```ts
let title = "工程师"  // 自动推断为 string，等价于 let title: string
```

**原则**: 能推断就不手写，推断不出来或不符合预期时才显式标注。

## 基本类型

```ts
let name: string = "张三"
let age: number = 25
let isDone: boolean = true
let empty: null = null           // 很少单独使用
let notAssigned: undefined = undefined // 很少单独使用
let big: bigint = 100n           // ES2020+，用得少
let id: symbol = Symbol("id")    // 唯一标识符，用得少
```

### null 和 undefined 的实际用法

很少单独标注，通常作为联合类型表示"可能为空"：

```ts
let name: string | null = null       // 可能为字符串，也可能为空
const el: HTMLElement | null = document.getElementById("app") // DOM查询
```

- `null` → 主动赋空值
- `undefined` → 未定义/未传

## 数组与元组

### 数组

```ts
let numbers: number[] = [1, 2, 3]        // 常用写法
let names: Array<string> = ["张三"]       // 泛型写法（等价）
```

### 联合类型数组

```ts
let mixed: (number | string)[] = [1, "two"]  // ✅ 括号不能省！
// number | string[] ❌ 意思是"要么number，要么字符串数组"
```

### 元组 (Tuple)

精确控制每个位置的类型和长度：

```ts
let user: [string, number] = ["张三", 25]
```

⚠️ **坑**: `push` 方法不受长度限制，但索引赋值会报错：

```ts
let coordinate: [number, number] = [1, 2]
coordinate.push(3)  // ✅ 不报错（历史遗留）
coordinate[2] = 3   // ❌ 报错
```

## 特殊类型

### any — 放弃类型检查

```ts
let x: any = "hello"
x = 123       // ✅ 不报错
x.foo()       // ✅ 不报错（运行时才崩）
```

### unknown — 安全版的 any

使用前必须做类型检查：

```ts
let y: unknown = "hello"
y.toUpperCase()  // ❌ 报错

if (typeof y === "string") {
  y.toUpperCase()  // ✅ 通过检查后可用
}
```

### void — 函数无返回值

```ts
const log = (msg: string): void => { console.log(msg) }
```

实际多自动推断，常见于定义回调类型：

```ts
type Callback = (data: string) => void
```

### never — 永远不会正常结束

```ts
function fail(msg: string): never {
  throw new Error(msg)  // throw 中断，不会执行到结尾
}
```

对比：`void` = 执行完没返回值，`never` = 根本执行不完。
