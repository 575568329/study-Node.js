## tsconfig.json 常用配置

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "CommonJS",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "outDir": "./dist",
    "rootDir": "./src",
    "baseUrl": "./src",
    "paths": { "@/*": ["./*"] }
  },
  "include": ["src/**/*"]
}
```

## strict 模式

`"strict": true` 开启所有严格检查。最重要的两个：

```ts
// strictNullChecks —— null/undefined 不能赋值给其他类型
let name: string = null  // ❌

// noImplicitAny —— 不允许隐式 any
function add(a, b) { }  // ❌ 参数隐式 any
```

**新项目一律开 strict。**

## 声明文件 (.d.ts)

给没有类型的 JavaScript 库补充类型信息：

```ts
// types/old-lib.d.ts
declare module "old-lib" {
  export function add(a: number, b: number): number
}
```

## @types 包

社区为流行库写好的类型声明：

```bash
npm install @types/node @types/express
```

| 场景 | 怎么办 |
|------|--------|
| 库自带类型 | 直接用，不用装 |
| 库没类型，社区补了 | `npm install @types/xxx` |
| 都没有 | 自己写 `.d.ts` |

**编辑器会自动提示**——装好 `@types/xxx` 后，VS Code 自动有类型补全，不用背 API。
