## 联合类型（|）与交叉类型（&）

```ts
// 联合 —— "或"，取其一
type Status = "active" | "inactive"

// 交叉 —— "且"，合并
type User = { name: string } & { age: number }
```

## 类型守卫（类型收窄）

TypeScript 看到 `string | number` 只允许用共有的方法。类型守卫告诉 TypeScript "在这个代码块里具体是什么类型"。

### typeof — 基本类型

```ts
if (typeof value === "string") {   // 注意是字符串 "string"，不是类型
  value.toUpperCase()  // ✅
}
```

### instanceof — 类实例

```ts
if (date instanceof Date) {
  date.getFullYear()  // ✅
}
```

### in — 对象属性

```ts
if ("swim" in animal) {
  animal.swim()  // ✅
}
```

### 自定义类型谓词 (is)

把类型判断逻辑封装成函数，让 TypeScript 理解：

```ts
function isFish(animal: Fish | Bird | Dog): animal is Fish {
  return animal.type === "fish"
}

if (isFish(animal)) {
  animal.swim()  // ✅ TypeScript 知道这里是 Fish
}
```

三种类型时用 if/else if/else 链式收窄：

```ts
if (isFish(animal)) { ... }
else if (isBird(animal)) { ... }
else { /* 只剩 Dog */ }
```

## 可辨识联合

多个类型有共同属性但值不同，通过这个属性区分：

```ts
interface Success { status: "success"; data: string }
interface Error   { status: "error";   message: string }

if (response.status === "success") {
  response.data     // ✅ 自动收窄
}
```

## 模板字面量类型（了解）

```ts
type Handler = `on${Capitalize<"click" | "focus">}`
// = "onClick" | "onFocus"
```

## 映射类型（了解原理）

工具类型的底层原理：

```ts
type MyReadonly<T> = {
  readonly [K in keyof T]: T[K]
}
```
