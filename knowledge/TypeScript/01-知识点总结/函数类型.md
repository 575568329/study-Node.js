# TS.3 函数类型

> 学习日期: 2026-03-30 | 置信度: 高

---

## 参数与返回值

```ts
function add(a: number, b: number): number {
  return a + b
}
// 返回值通常可自动推断，不手写
```

## 可选参数 vs 默认参数

```ts
// 可选参数 —— 不传时为 undefined（不是 null！）
function greet(name: string, title?: string): string {
  if (title) return `${title}. ${name}`
  return name
}

// 默认参数 —— 不传时用默认值
function greet(name: string, title: string = "同学"): string {
  return `${title}. ${name}`
}
```

| 方式 | 不传时的值 | 需要判空吗 |
|------|-----------|-----------|
| 可选 `title?` | `undefined` | 需要 |
| 默认 `title = "同学"` | `"同学"` | 不需要 |

⚠️ 可选参数必须在必选参数后面。

**实际开发优先用默认参数**，减少内部判空。

## 剩余参数

```ts
function sum(...numbers: number[]): number {
  return numbers.reduce((a, b) => a + b, 0)
}
```

## 函数重载（Overload）

同一个函数，不同参数类型对应不同行为：

```ts
function process(input: string): number
function process(input: number): number
function process(input: string | number): number {
  if (typeof input === "string") return input.length
  return input * 2
}
```

实际开发中用得少，联合类型通常够用。重载价值在于**返回值类型不同**时。
