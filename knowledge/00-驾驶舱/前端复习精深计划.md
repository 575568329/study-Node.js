# 前端复习精深计划（费曼学习法版）

**创建时间**：2026-07-15
**适用范围**：已学内容的复习与精深（独立于 Java 学习计划）
**检验方式**：合上资料，自己讲 / 自己写
**优先级**：JS/TS 基础 → Vue3 → CSS → Node.js → React/Next/AI

---

## 一、为什么要有这份计划（先认清问题）

**错误归因**：以为自己"学得不够多、不够精深"。
**真实问题**：学了很多，但几乎只做"输入"，从不做"输出"。

知识没经过"主动提取"就会流走。Vue3/React/Node.js 讲不出，
不是没学会，是学会后从来没有合上资料、逼自己复述一遍。

> **复习 ≠ 再看一遍笔记。** 再看一遍只会制造"我好像会了"的错觉，
> 面试时照样一片空白。有效复习 = 合上资料 → 自己讲 → 被追问 → 补漏。

---

## 二、核心方法：费曼四步法

每个知识点都走这四步，一步都不能省：

1. **蒙眼默写**：合上所有资料，看着自测问题，在白纸/文档上写出答案。
2. **标红卡壳**：写不出、写得含糊的地方，立刻标红 —— 这就是真盲区。
3. **翻书补漏**：只针对标红的部分翻资料，看懂后合上再默写一遍。
4. **产出讲稿**：整理成"3 分钟能讲清 + 扛得住追问"的讲稿。

**关键**：复习的产物不是笔记，是**面试讲稿**。复习和面试准备合二为一。

## 七、和 AI 配合的用法

- **自测**：看着上面的问题，先自己在文档里写答案，别翻资料。
- **验证**：写完把你的答案发给我，我当面试官逐条判 ✅/⚠️/❌，客观不迎合。
- **追问**：对你答得含糊的点，我连续追问 5 层，逼出真盲区。
- **补漏**：盲区确认后，我给你官方文档出处 + 讲清原理，你再合上默写一遍。

> 记住：判断标准是"能不能对着一个真人流畅讲 3 分钟并扛住追问"，
> 不是"我看过、我好像懂"。
