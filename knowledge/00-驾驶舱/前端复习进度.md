7. ✅ Q7 z-index 层叠上下文：拼爹机制 + 隐形触发 + Portal/Teleport 底层原因

**关键收获**：
- position 5 取值各自"相对谁"：static 不定位 / relative 相对自身原位（不脱流）/ absolute 相对最近已定位祖先（脱流）/ fixed 相对视口 / sticky 粘性
- absolute 锚点规则：向上找**第一个 position 非 static** 的祖先（relative/absolute/fixed/sticky 都算锚），找不到才回退视口
- relative 占坑（不脱流）vs absolute 抽坑（脱流）—— 本质区别
- z-index 不是全局比大小，是"先比父上下文（拼爹）"；99999 只在自己家横
- 隐形触发层叠上下文：opacity<1 / transform / filter / fixed / sticky（实际项目 modal 盖不住的根因）
- 串起 Vue Teleport / React Portal 存在的底层原因（躲开被污染的祖先上下文）

**错题本**（迁移失败 / 概念模糊，复习重点）：
- 🔴 **概念模糊**：absolute "相对谁" 答成"相对自己"（那是 relative）→ 已纠正为"最近已定位祖先"
- 🔴 **规则记反**：absolute 锚点说成"找第一个不是 absolute 的" → 正确是"找第一个不是 static 的"（absolute 本身也能当锚）。同一段代码两条规则给不同答案，是最危险的错法
- 🔴 **概念糅合**：relative/absolute 坑位问题答成"占着+被占据"自相矛盾，且误用"浮动"（那是 float）→ 已拆清：relative 占坑不脱流、absolute 抽坑脱流；float ≠ absolute
