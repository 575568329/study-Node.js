# GraphSearch 混合搜索模式

> Day 6（2026-05-05）

---

## 核心概念

图谱搜索采用固定搜索栏 + 快捷键 + 模态面板的混合交互模式。

## 交互设计

| 触发方式 | 说明 |
|---------|------|
| 固定搜索栏 | 常驻在图谱页面顶部，随时可以输入 |
| Ctrl+K 快捷键 | 快速唤起搜索，符合 VS Code 等工具的用户习惯 |
| 模态结果面板 | 搜索结果以模态弹窗形式展示，不遮挡图谱 |

## 结果交互

1. 用户输入关键词
2. 调用 `/api/graph?mode=search&q=关键词`
3. 模态面板展示匹配的节点列表
4. 点击结果 → 图谱自动定位到对应节点（centerAt + zoom）

## 设计参考

- **Command Palette 模式**: VS Code、Notion 等工具使用 Ctrl+K 唤起搜索
- **固定搜索栏**: NN/g（尼尔森诺曼集团）研究表明，常驻搜索框比隐藏搜索更易发现
- **混合模式**: 兼顾"新手发现"（固定搜索栏）和"效率用户"（快捷键）

## 面试要点

- 为什么用混合搜索模式？（兼顾新手和效率用户）
- 搜索结果如何定位到图谱节点？（centerAt + zoom 动画）
- Ctrl+K 的用户习惯来自哪里？（VS Code Command Palette）
