# 文件向量存储实现（FileStore）

> 学习日期: 2026-05-03 | 置信度: ⭐⭐⭐⭐

---

## 核心概念

用 JSON 文件（data/vectors.json）存储向量数据，按 collectionName 分组。
配合策略模式（VectorStore 接口），可切换到 Chroma 等向量数据库。

## 代码示例

```typescript
// 数据结构
{
  "kb-know_0": {
    "ids": ["kbknow_0-chunk-0", "kbknow_0-chunk-1"],
    "texts": ["切片文本1", "切片文本2"],
    "vectors": [[0.01, 0.02, ...], [0.03, 0.04, ...]]
  }
}

// 核心操作
addVectors(collection, vectors, texts, ids)  // 追加向量
similaritySearch(collection, queryVector, topK)  // 余弦相似度搜索
deleteCollection(collection)  // 删除集合
count(collection)  // 统计向量数量
```

## 关键要点
1. 写入前必须 `mkdirSync({ recursive: true })`，否则首次运行报 ENOENT
2. 使用 `path.resolve()` 绝对路径，避免工作目录不同导致路径错乱
3. 余弦相似度 = 向量点积 / (|A| × |B|)，范围 [-1, 1]
4. 每次操作都是"读全量 → 修改 → 写全量"，适合小规模数据

## ❌ 常见错误与纠正（复习重点）⚠️

### 错误1：相对路径导致找不到文件
- **错误示例**: `const filePath = './data/vectors.json'`
- **错误原因**: 相对路径依赖于进程启动目录，Next.js dev server 的 cwd 可能不是项目根目录
- **正确理解**: 用 `path.resolve('data/vectors.json')` 得到绝对路径

### 错误2：目录不存在导致写入失败
- **错误示例**: 直接 `writeFileSync`，data/ 目录未创建
- **错误原因**: 首次运行或清理数据后目录不存在
- **正确理解**: 写入前 `fs.mkdirSync(path.dirname(filePath), { recursive: true })`
