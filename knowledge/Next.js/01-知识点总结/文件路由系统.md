# 文件路由系统（App Router）

> 学习日期: 2026-04-07 | 置信度: 高

---

## 核心概念

Next.js 的路由由**文件路径自动生成**，无需手动配置路由表。

## 路由映射规则

```
文件位置                        → 路由
app/page.tsx                   → /
app/about/page.tsx             → /about
app/blog/page.tsx              → /blog
app/blog/[id]/page.tsx         → /blog/123（动态路由）
```

## 关键规则

1. **文件夹名 = 路由路径**
2. **page.tsx = 该路由的页面组件**（必须是 export default）
3. **route.ts = 该路径的 API 接口**
4. **page.tsx 和 route.ts 不能在同一目录下**（会冲突）

## 动态路由

```tsx
// app/blog/[id]/page.tsx
// Next.js 15+: params 是 Promise，必须 await
export default async function BlogPost({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params
  return <div>文章 #{id}</div>
}
```

## Layout 嵌套

- layout.tsx 按文件夹层级嵌套（俄罗斯套娃）
- **子目录的 layout 只影响子路由**，不影响其他路由
- 根 layout（app/layout.tsx）影响所有页面

```
app/layout.tsx          → 所有页面
app/blog/layout.tsx     → 只影响 /blog/* 路由
```

## ❌ 常见错误

### 错误: 同路径 route.ts 和 page.tsx 冲突
- **错误**: `app/api/tasks/page.tsx` 和 `app/api/tasks/route.ts` 同时存在
- **原因**: 同一路径不能既是 API 又是页面
- **正确**: 页面放 `app/tasks/page.tsx`，API 放 `app/api/tasks/route.ts`
