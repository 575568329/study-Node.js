## 🎯 项目概述

电影管理系统，包含用户认证、电影CRUD、人员管理（导演+演员）、评论评分功能。

### 数据库设计（5张表）

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| users | 用户表 | account, password, name, gender, bio |
| movies | 电影表 | name, releaseDate, company, description, genre, rating, duration, cover |
| persons | 人员表(导演+演员) | name, gender, age, nationality |
| movie_person | 中间表(多对多) | movieId, personId, role(director/actor) |
| comments | 评论表 | userId, movieId, content, score |

## 💡 关键要点

### 1. Sequelize 模型定义
- `allowNull: false` — 必填字段
- `unique: true` — 唯一约束
- `DataTypes.ENUM('male', 'female')` — 枚举类型，限制值范围
- `DataTypes.DECIMAL(2, 1)` — 精确小数，适合评分(8.8)
- `DataTypes.DATEONLY` — 只存日期不存时间
- `field: 'release_date'` — 驼峰命名→蛇形命名映射

### 2. 多对多关系（中间表）
- 一部电影有多个演员，一个演员演多部电影 → 多对多
- 方案：通过中间表 `movie_person` 实现
- `role` 字段用 ENUM('director', 'actor') 区分导演/演员
- **不能用逗号分隔存ID**：`1,5,12` 查询 `LIKE '%5%'` 会匹配到15、25

### 3. 模型关联方式
```
// 一对多
User.hasMany(Comment, { foreignKey: 'userId', as: 'comments' })
Comment.belongsTo(User, { foreignKey: 'userId', as: 'user' })

// 多对多（通过中间表）
Movie.hasMany(MoviePerson, { foreignKey: 'movieId', as: 'moviePerson' })
MoviePerson.belongsTo(Movie, { foreignKey: 'movieId', as: 'movie' })
Person.hasMany(MoviePerson, { foreignKey: 'personId', as: 'moviePerson' })
MoviePerson.belongsTo(Person, { foreignKey: 'personId', as: 'person' })
```

### 4. belongsToMany vs 两组一对多
- `belongsToMany` + `through`：Sequelize标准写法，但无法用role过滤
- **两组一对多**：可以通过 `where: { role: 'director' }` 精确查询导演/演员

### 5. bulkCreate 批量创建
```javascript
await MoviePerson.bulkCreate(
  directorIds.map(personId => ({ movieId: movie.id, personId, role: 'director' }))
);
```

## ❌ 常见错误与纠正（复习重点）⚠️

### 错误1：INTEGER 类型存小数
- **错误**: `score` 字段用 `INTEGER`，评分 8.5 会被截断为 8
- **正确**: 用 `DECIMAL(2, 1)` 存评分

### 错误2：拼写错误导致找不到模块
- **错误**: 文件名 `MoviePersion.js`（persion），require 时找不到 `MoviePerson`
- **纠正**: 仔细检查拼写，Person 不是 Persion

### 错误3：多对多用逗号分隔存ID
- **错误**: 电影表直接存 `actor_ids: "1,5,12"`
- **原因**: 查询时 `LIKE '%5%'` 匹配到 15、25、50
- **正确**: 使用中间表，每条关联记录一行

### 错误4：define 名称与文件名不一致
- **错误**: `sequelize.define('MoviePersion', ...)` 但文件名是 `MoviePerson.js`
- **纠正**: 两者保持一致

### 易错点总结
1. DECIMAL 用于评分，INTEGER 用于时长
2. 多对多必须用中间表，不要用逗号分隔
3. 驼峰命名（JS）vs 蛇形命名（DB）需要 field 映射
4. define 的第一个参数要和文件名保持一致
