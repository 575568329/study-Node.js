# 密码加密（bcrypt）

## 📚 核心概念

### 为什么不能存明文密码？

**场景示例**：
```
1. 数据库泄露
   → 黑客入侵数据库
   → 直接拿到所有用户的明文密码
   → 拿到密码去试其他网站（撞库攻击）💸

2. 内部人员泄露
   → 管理员恶意查看用户密码
   → 员工离职带走数据
   → 信任崩塌

3. 真实案例
   → 2019年Facebook 2.7亿个明文密码泄露
   → 2020年某公司因存明文密码被罚款2000万
```

---

## 🔐 密码加密方式对比

### MD5（已过时）

**问题**：
```javascript
const md5 = require('md5');
const hash = md5('123456');  // e10adc3949ba59abbe56e057f20f883e

❌ 彩虹表攻击：常见密码的MD5值预先计算好
❌ 相同密码永远生成相同哈希
❌ 快速计算：一秒能算几十亿次（容易被暴力破解）
```

**MD5问题演示**：
```javascript
md5('123456')  // → e10adc3949ba59abbe56e057f20f883e（第1次）
md5('123456')  // → e10adc3949ba59abbe56e057f20f883e（第2次，相同！）
// 黑客可以预先计算好100万个常见密码的MD5值
// 然后对比数据库中的哈希值，瞬间破解！
```

---

### bcrypt（推荐）✅

**优势**：
```javascript
const bcrypt = require('bcrypt');

bcrypt.hash('123456', 10)  // → $2b$10$abc...xyz（第1次）
bcrypt.hash('123456', 10)  // → $2b$10$def...uvw（第2次，不同！）

✅ 自动加盐：每次加密都加随机字符串
✅ 慢速计算：故意设计得很慢，防止暴力破解
✅ 可调强度：通过cost参数调整计算时间
```

---

## 💡 bcrypt详解

### Salt（盐）

**定义**：随机字符串，在加密前添加到密码中

**作用**：
```javascript
// 没有盐
hash('123456')  // → 永远生成相同的哈希值
// → 黑客用彩虹表攻击

// 有盐
hash('123456' + '随机盐abc')  // → $2b$10$abc...xyz
hash('123456' + '随机盐def')  // → $2b$10$def...uvw（不同！）
// → 每次结果不同，彩虹表失效
```

**bcrypt自动加盐**：
```javascript
// bcrypt自动生成盐并包含在哈希值中
const hash = bcrypt.hashSync('123456', 10);
// $2b$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
//   ↑   ↑   ↑
//  算法 成本 盐+哈希
```

---

### Salt Rounds（加密强度）

**定义**：加密循环次数（2^rounds次）

**计算公式**：
```javascript
bcrypt.hash(password, 10)  // 2^10 = 1024次循环
bcrypt.hash(password, 12)  // 2^12 = 4096次循环
bcrypt.hash(password, 14)  // 2^14 = 16384次循环
```

**时间对比**：
```javascript
// 测试：加密1000次
bcrypt.hash('123456', 8)   // 约0.04秒/次
bcrypt.hash('123456', 10)  // 约0.16秒/次（推荐）✅
bcrypt.hash('123456', 12)  // 约0.64秒/次
bcrypt.hash('123456', 14)  // 约2.56秒/次
```

**为什么故意设计得很慢？**
```
✅ 正常用户：注册/登录等0.16秒完全OK
❌ 黑客暴力破解：
   - rounds=10：每秒只能试6个密码
   - rounds=12：每秒只能试1.5个密码
   - rounds=14：每秒只能试0.4个密码
```

**推荐值**：**10-12**
- 10：平衡安全性和性能（推荐）
- 12：更高的安全性（适合高敏感场景）

## 💻 代码示例

### 安装
```bash
npm install bcrypt
```

### 基础用法

**1. 加密密码**
```javascript
const bcrypt = require('bcrypt');

// 异步（推荐）
async function hashPassword(password) {
  const saltRounds = 10;
  const hashedPassword = await bcrypt.hash(password, saltRounds);
  console.log('加密后的密码:', hashedPassword);
  // $2b$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
  return hashedPassword;
}

// 同步
const hashedPassword = bcrypt.hashSync('123456', 10);
```

**2. 验证密码**
```javascript
// 异步（推荐）
async function verifyPassword(plainPassword, hashedPassword) {
  const isMatch = await bcrypt.compare(plainPassword, hashedPassword);
  if (isMatch) {
    console.log('密码正确');
  } else {
    console.log('密码错误');
  }
}

// 同步
const isMatch = bcrypt.compareSync('123456', hashedPassword);
```

### 实际应用：用户注册/登录

```javascript
const express = require('express');
const bcrypt = require('bcrypt');
const app = express();

app.use(express.json());

// 用户注册
app.post('/api/register', async (req, res) => {
  const { username, password } = req.body;

  try {
    // 1. 加密密码
    const saltRounds = 10;
    const hashedPassword = await bcrypt.hash(password, saltRounds);

    // 2. 保存到数据库（保存加密后的密码）
    await db.users.insert({
      username,
      password: hashedPassword  // ⚠️ 永远不要保存明文密码！
    });

    res.json({ success: true, message: '注册成功' });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});

// 用户登录
app.post('/api/login', async (req, res) => {
  const { username, password } = req.body;

  try {
    // 1. 从数据库查询用户
    const user = await db.users.findOne({ username });
    if (!user) {
      return res.status(401).json({ error: '用户不存在' });
    }

    // 2. 验证密码
    const isMatch = await bcrypt.compare(password, user.password);
    if (!isMatch) {
      return res.status(401).json({ error: '密码错误' });
    }

    // 3. 生成Token（JWT）
    const token = jwt.sign({ id: user.id }, JWT_SECRET);

    res.json({ success: true, token });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});
```

## 🔍 bcrypt哈希值结构

**格式**：
```
$2b$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
↑  ↑  ↑                    ↑
算法 成本      盐+哈希值
```

**解析**：
```javascript
const hash = '$2b$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy';

const parts = hash.split('$');
console.log('算法版本:', parts[1]);  // 2b
console.log('Salt Rounds:', parts[2]);  // 10
console.log('盐+哈希:', parts[3]);  // N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
```

**关键理解**：
- ✅ 盐已经包含在哈希值中（不需要单独存储）
- ✅ 验证时自动从哈希值中提取盐
- ✅ 每次加密结果不同（因为盐不同）

## 🧪 测试演示

### 演示1：相同密码，不同哈希
```javascript
bcrypt.hash('123456', 10)
  .then(hash1 => {
    console.log('第1次:', hash1);
    return bcrypt.hash('123456', 10);
  })
  .then(hash2 => {
    console.log('第2次:', hash2);
    // 结果完全不同！
  });

// 输出示例：
// 第1次: $2b$10$abc...xyz
// 第2次: $2b$10$def...uvw（不同！）
```

### 演示2：验证密码
```javascript
const storedHash = '$2b$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy';

bcrypt.compare('123456', storedHash)
  .then(isMatch => {
    console.log('验证123456:', isMatch);  // true
    return bcrypt.compare('wrongpass', storedHash);
  })
  .then(isMatch => {
    console.log('验证wrongpass:', isMatch);  // false
  });
```

### 演示3：加密强度对比
```javascript
console.time('bcrypt(8)');
bcrypt.hash('123456', 8).then(() => console.timeEnd('bcrypt(8)'));
// 约0.04秒

console.time('bcrypt(10)');
bcrypt.hash('123456', 10).then(() => console.timeEnd('bcrypt(10)'));
// 约0.16秒

console.time('bcrypt(12)');
bcrypt.hash('123456', 12).then(() => console.timeEnd('bcrypt(12)'));
// 约0.64秒

// salt rounds每增加2，耗时增加约4倍
```

## ⚠️ 安全注意事项

### ❌ 不要做的事

```javascript
// 1. 不要保存明文密码
await db.users.insert({ username, password });  // ❌ 危险！

// 2. 不要使用可逆加密
const encrypted = encrypt(password);  // ❌ 可以解密！

// 3. 不要使用快速哈希
const hash = md5(password);  // ❌ 太快了！

// 4. 不要在前端加密
const hashed = await bcrypt.hash(password, 10);  // ❌ 不安全！

// 5. 不要使用过低的salt rounds
const hashed = await bcrypt.hash(password, 4);  // ❌ 太低了！
```

### ✅ 应该做的事

```javascript
// 1. 只在后端加密
const hashedPassword = await bcrypt.hash(password, 10);  // ✅

// 2. 使用推荐值
const saltRounds = 10;  // ✅ 推荐
const saltRounds = 12;  // ✅ 高安全场景

// 3. 验证时使用compare
const isMatch = await bcrypt.compare(plainPassword, hashedPassword);  // ✅

// 4. 敏感操作需要重新验证
app.post('/api/change-password', async (req, res) => {
  const { oldPassword, newPassword } = req.body;

  // 验证旧密码
  const isMatch = await bcrypt.compare(oldPassword, user.password);
  if (!isMatch) {
    return res.status(401).json({ error: '旧密码错误' });
  }

  // 加密新密码
  const newHashedPassword = await bcrypt.hash(newPassword, 10);
  // ...保存到数据库
});
```

## 📝 总结

**bcrypt vs MD5**：
- ✅ bcrypt：自动加盐、慢速计算、可调强度、防止彩虹表
- ❌ MD5：快速计算、相同密码相同哈希、容易被破解

**Salt Rounds**：
- 不是过期时间！是加密强度
- 推荐值：10-12
- 每增加2，耗时增加4倍

**使用流程**：
```javascript
// 注册时
const hashedPassword = await bcrypt.hash(password, 10);

// 登录时
const isMatch = await bcrypt.compare(plainPassword, hashedPassword);
```

**记住**：永远不要保存明文密码！使用bcrypt加密！
