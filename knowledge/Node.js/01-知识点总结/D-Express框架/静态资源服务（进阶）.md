# 静态资源服务（进阶）

## 📚 核心概念

静态资源服务是指让Express提供HTML、CSS、JavaScript、图片、字体等文件的访问功能。

---

## 🔧 基础用法

### express.static() 中间件

```javascript
const express = require('express');
const app = express();

// 提供静态文件
app.use(express.static('public'));

// 访问：http://localhost:3000/images/logo.png
// 实际文件：public/images/logo.png
```

## 💡 高级用法

### 1️⃣ 多个静态目录

```javascript
// 静态资源
app.use('/static', express.static('public'));

// 上传文件
app.use('/uploads', express.static('uploads'));

// 访问：
// http://localhost:3000/static/images/logo.png
// http://localhost:3000/uploads/avatars/user.jpg
```

---

### 2️⃣ 虚拟路径前缀

```javascript
// 文件在：public/assets/images/logo.png
// 访问路径：/static/images/logo.png
app.use('/static', express.static('public/assets'));

// 访问：http://localhost:3000/static/images/logo.png
// 实际文件：public/assets/images/logo.png
```

---

### 3️⃣ 设置缓存

```javascript
// 开发环境：不缓存
app.use(express.static('public'));

// 生产环境：缓存1天
app.use(express.static('public', {
  maxAge: '1d',  // 1天
  etag: true,    // 启用ETag
  lastModified: true  // 启用Last-Modified
}));

// 更精确的控制
const expressStatic = express.static('public', {
  maxAge: 0,  // 不缓存（默认）
  setHeaders: (res, path) => {
    // 图片缓存1天
    if (path.match(/\.(jpg|jpeg|png|gif|webp)$/i)) {
      res.setHeader('Cache-Control', 'public, max-age=86400');  // 1天
    }
    // CSS/JS缓存1小时
    else if (path.match(/\.(css|js)$/i)) {
      res.setHeader('Cache-Control', 'public, max-age=3600');  // 1小时
    }
    // HTML不缓存
    else if (path.match(/\.html$/i)) {
      res.setHeader('Cache-Control', 'no-cache');
    }
  }
});

app.use(expressStatic);
```

---

### 4️⃣ 自�认文件

```javascript
// 默认查找index.html
app.use('/static', express.static('public'));

// 访问：http://localhost:3000/static/
// 返回：public/index.html

// 自定义默认文件
app.use('/static', express.static('public', {
  index: ['default.html', 'index.html']
}));

// 禁用默认文件
app.use('/static', express.static('public', {
  index: false
}));
```

## 🎯 实际应用示例

### 你的博客项目

```javascript
// app.js

// ===== 静态文件 =====
app.use('/uploads', express.static('uploads'));

// 访问上传的图片
// http://localhost:3000/uploads/avatars/avatar-xxx.jpg
// http://localhost:3000/uploads/covers/cover-xxx.jpg
```

**为什么使用虚拟路径？**

```javascript
// ❌ 不推荐：直接暴露目录
app.use(express.static('uploads'));
// 访问：http://localhost:3000/avatars/avatar-xxx.jpg

// ✅ 推荐：使用虚拟路径前缀
app.use('/uploads', express.static('uploads'));
// 访问：http://localhost:3000/uploads/avatars/avatar-xxx.jpg
```

**优点**：
- ✅ 路径清晰（一看就知道是上传文件）
- ✅ 方便管理（可以随时更改前缀）
- ✅ 避免冲突（不会和API路由冲突）

## 🤔 常见问题

### Q1: express.static() 和路由的优先级？

**A**: Express按定义顺序匹配

```javascript
// 1️⃣ 静态文件先定义
app.use('/static', express.static('public'));

// 2️⃣ API路由后定义
app.get('/static/api/data', (req, res) => {
  // 这个路由不会被访问到！
  // 因为静态文件中间件已经处理了 /static/*
});

// ✅ 正确的做法
// API路由先定义
app.get('/api/data', (req, res) => { ... });

// 静态文件后定义
app.use('/static', express.static('public'));
```

---

### Q2: 如何防止目录遍历攻击？

**A**: express.static() 已自动处理

```javascript
// 攻击请求：/uploads/../../../etc/passwd
app.use('/uploads', express.static('uploads'));

// Express自动返回：404 Not Found
// ✅ 安全！
```

---

### Q3: 如何限制访问的文件类型？

**A**: 使用自定义中间件

```javascript
const allowExtensions = ['.jpg', '.jpeg', '.png', '.gif', '.webp'];

app.use('/uploads', (req, res, next) => {
  const ext = path.extname(req.path).toLowerCase();

  if (!allowExtensions.includes(ext)) {
    return res.status(403).json({ message: '不允许访问此文件类型' });
  }

  next();
});

app.use('/uploads', express.static('uploads'));
```

## 🎯 最佳实践

### 1️⃣ 分离静态资源和上传文件

```javascript
// 静态资源（可缓存）
app.use('/static', express.static('public', {
  maxAge: '1d',
  etag: true
}));

// 上传文件（可缓存，但要注意权限）
app.use('/uploads', express.static('uploads', {
  maxAge: '1h',
  etag: true
}));
```

---

### 2️⃣ 使用CDN

```javascript
// 开发环境：本地静态文件
if (process.env.NODE_ENV === 'development') {
  app.use('/static', express.static('public'));
} else {
  // 生产环境：重定向到CDN
  app.use('/static', (req, res, next) => {
    res.redirect(`https://cdn.example.com${req.path}`);
  });
}
```

---

### 3️⃣ 压缩响应

```javascript
const compression = require('compression');

// 压缩所有响应
app.use(compression());

// 然后再提供静态文件
app.use(express.static('public'));
```

---

### 4️⃣ 安全设置

```javascript
const helmet = require('helmet');

app.use(helmet());

// 静态文件
app.use('/uploads', express.static('uploads', {
  // 防止目录遍历
  redirect: false,
  // 不显示目录索引
  index: false
}));
```
