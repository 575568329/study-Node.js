# 泛型组件

> 学习日期: 2026-04-03 | 置信度: 中

---

## 核心概念

TypeScript 泛型在 React 组件中的应用。让一个组件支持多种数据类型，而不是为每种类型写一个组件或用 `any`。

### 语法

```tsx
function 组件名<T>(props: Props类型<T>) {
  // T 由使用时决定
}
```

### 示例

```tsx
interface ListProps<T> {
  items: T[]
  render: (item: T) => React.ReactNode
}

function List<T>({ items, render }: ListProps<T>) {
  return <ul>{items.map((item, i) => <li key={i}>{render(item)}</li>)}</ul>
}

// 使用 — T 自动推导为不同类型
<List items={['a', 'b', 'c']} render={(s) => <span>{s}</span>} />
<List items={[1, 2, 3]} render={(n) => <span>{n}</span>} />
<List items={[{ id: 1, name: '张三' }]} render={(u) => <span>{u.name}</span>} />
```

## 关键要点

1. 解决的问题：一个组件支持多种数据类型
2. `React.ReactNode` = 所有能渲染的东西（string、number、null、JSX）
3. `JSX.Element` 只接受 JSX，比 React.ReactNode 更窄
4. 大写开头函数在 JSX 中当组件用：`<List />`
5. Vue3 的 defineProps 不支持完整的泛型组件写法

## React 组件命名规则

```
大写开头 → React 当组件 → <MyButton />
小写开头 → React 当 HTML 标签 → <div />
```
