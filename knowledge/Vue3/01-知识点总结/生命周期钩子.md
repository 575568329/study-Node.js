## Vue3 vs Vue2 映射

| Vue2 | Vue3 Composition API |
|------|---------------------|
| `beforeCreate`/`created` | 不需要（`<script setup>` 顶层代码就是） |
| `beforeMount` | `onBeforeMount` |
| `mounted` | `onMounted` |
| `beforeUpdate` | `onBeforeUpdate` |
| `updated` | `onUpdated` |
| `beforeDestroy` | `onBeforeUnmount` |
| `destroyed` | `onUnmounted` |

## 关键点

`<script setup>` 顶层代码在组件创建时立即执行，**比 onMounted 更早**：

```
1. <script setup> 顶层代码  ← setup() 阶段
2. onBeforeMount
3. onMounted                ← DOM 可用
```
