## 5. 核心业务难点

### 5.1 题库数据适配

- 题库数据类型：选择题、填空题、主观题、公式题、图片题、相似题、同类题、基本学力、澳门知识点、试题/试卷标签、教辅/教材目录、专题试题与试卷。
- 接口返回数据复杂度：涉及业务来源、资源语言、题型、新老题型、学段学科、教材版本/册别、基本学力第一/第二语言、澳门知识点等多维条件。
- 多语言字段组织：代码中可见 `languageCode`、`language`、`languageName`、`languageLabel` 等字段；接口注释包含 `zh_CN`、`zh_TW`、`en_US`、`pt_BR`。
- 前端转换 / 映射 / 兜底：按资源语言获取下拉数据，按 `secondBizSource` 和 `languageCode` 回显试题来源；澳门题目跳过部分大陆新老题型校验；语言缺失时保持大陆默认数据或做空值兜底。
- 历史脏数据 / 格式不统一：提交中多次处理回显为空、重复数据、语言切换未清空、接口返回空时报错、题型和知识点判断误覆盖等问题。

### 5.2 富文本与公式

- CKEditor 使用场景：题库/教材/专题/资源内容编辑与展示；`tkms-fresh-web` 引入 `@zx/ckeditor`，`rmp` 中有富文本插件和图片上传相关改造。

- 图片兜底：公式解析失败、`data-latex-special` 或异常 LaTeX 时使用原始图片兜底，避免题目内容丢失。
- 性能和兼容：处理过 MathJax 重复渲染、DOM 未就绪重试、图片上传默认宽度、公式和图片拖动、富文本 XSS 配置、构建内存不足等问题。

## 9. 典型问题案例

### 案例 1：资源语言联动导致下拉数据和回显错误

- 问题：图书、教辅、目录、需求管理等页面切换资源语言后，版本、册别、出版社、学科、试题来源等下拉数据仍显示旧语言或回显异常。
- 原因：旧页面默认按大陆业务数据加载，下拉数据与资源语言、业务来源没有形成统一联动，部分编辑弹窗切换语言后未清空依赖字段。
- 我的解决方案：在前端请求中透传 `languageCode` / `languageName`，切换资源语言时清空依赖字段并重新请求；后端 `gxh-erm` 增加按语言返回阶段、学科、版本、册别、出版社等下拉名称的处理。
- 结果：澳门资源语言筛选、编辑回显和目录数据按语言展示，减少错选和脏数据提交风险。
- 面试可以怎么讲：重点讲“语言切换不是简单替换文案，而是业务数据维度切换，需要处理依赖字段清空、默认值、编辑回显和大陆流程不受影响”。

### 案例 2：富文本公式从图片到 MathJax 渲染的兼容

- 问题：基本学力和题目内容中的公式、图片在富文本展示/编辑中存在渲染失败、拖动异常、样式错位、图片默认宽度不一致等问题。
- 原因：历史数据中 Wiris 公式以图片标签存在，部分公式缺少有效 LaTeX 或包含 Math input error；MathJax 渲染时机和 DOM 就绪状态不稳定。
- 我的解决方案：将可识别的 `data-latex` 转换为 LaTeX 行内公式交给 MathJax 渲染；无法识别或特殊公式保留图片展示；增加渲染检测、重试、失败日志和图片样式兜底。
- 结果：公式内容在题库和基本学力场景中展示更稳定，异常公式不会直接丢失。
- 面试可以怎么讲：重点讲“兼容历史数据比理想化重构更重要，通过分级兜底保证内容正确性优先”。

### 案例 3：众包流程澳门题型和基本学力适配

- 问题：众包审核、校对、标注、纠错、解析对比、同类题/相似题页面中，澳门题目无法正确展示基本学力、澳门知识点、题型或试题来源。
- 原因：原流程按大陆题型和新课标知识点判断，澳门业务需要按业务来源和资源语言获取不同枚举和题目属性。
- 我的解决方案：在相关页面和公共组件中增加澳门判断，按 `secondBizSource`、`languageCode`、`isMacaoStudio` 获取试题来源、题型、目录和知识点；增加基本学力第一/第二语言展示组件和回显逻辑。
- 结果：众包多流程可识别澳门题目，减少审核和纠错环节的信息缺失。
- 面试可以怎么讲：重点讲“同一套加工流程服务两套业务规则，通过参数隔离和组件适配避免复制一套流程”。

### 案例 4：澳门专题和教材管理的数据隔离

- 问题：精品专题管理、题库教材管理、屏蔽管理等页面中，澳门与大陆数据混用，专题类型、教材版本、发布语言和发布业务配置不准确。
- 原因：旧接口默认查询大陆数据，部分页面菜单或查询条件写死，缺少 `isMacao` 参数和发布语言维度。
- 我的解决方案：在专题类型、排序、教材版本、屏蔽范围等接口增加 `isMacao` 或默认语言参数；新增发布语言和发布业务配置；调整无数据提示、布局换行和编辑回显。
- 结果：澳门专题和教材管理流程可独立配置，避免影响大陆数据。

### 案例 5：构建与安全配置问题

- 问题：旧 Vue 项目构建内存不足、覆盖度插桩影响大文件、生产 source map 存在安全隐患。

- 我的解决方案：调整 Node 构建内存、覆盖度插桩范围、生产环境 `productionSourceMap` 配置和相关依赖版本。
- 结果：降低构建失败和源码泄露风险。
- 面试可以怎么讲：重点讲“老项目不适合大规模升级，优先通过小范围构建配置优化解决交付风险”。
