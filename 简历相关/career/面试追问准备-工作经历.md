# 工作经历 - 面试追问准备（待补充）

---

## 🔔 为什么要重点提醒这些内容

简历里**加粗和量化的内容,本质是给面试官的"提问钩子"**——加粗 = "这条我很自信,来问我"。面试官扫到加粗数字(25% / 50% / 4 月无 P2 / 3 省 5 项目),几乎 100% 会追问"怎么做到的"或"具体说说"。

### 为什么数字类内容尤其要重点准备

1. **数字最容易被深挖,也最难糊弄**
   - 定性描述("提升了开发效率")可以泛泛而谈,面试官难辨真伪。
   - 但具体数字("提升 25%")面试官会追问:**方法是什么?对比基线是什么?怎么测算的?** 答不圆就暴露水分。

2. **讲不圆的代价 > 不写**
   - 如果简历写了"+25%"但答不出怎么做到,面试官会怀疑整份简历的真实性("这数字是不是编的?")。
   - 比压根不写更糟——不写只是没亮点,写了讲不出是"诚信问题"。

3. **同一段经历里"强 / 弱"并存会被对照**
   - 讯飞工作经历同时出现:
     - "基本 CRUD 开发"(AI 全栈转型条,偏入门)
     - "注解 + 切面 + 异常处理器"(i18n 条,偏进阶)
   - 面试官会问:"你后端到底什么水平?" 必须能自洽解释(见讯飞「层次自洽」)。

### 准备原则

每个加粗数字 / 量化点,都要能讲 **2-3 分钟**:
- **怎么做到的**(具体方法/机制)
- **对比基线**(从多少到多少 / 之前什么情况)
- **你的角色**(你主导还是参与,你做了哪部分)

讲不圆的,宁可把数字调保守(如 25% → "明显提升")或直接去掉。

## 一、科大讯飞 · 百得思维（2025.07 - 至今）

> 简历 bullets(2026-07-13 版):
> 1. **前端团队效能:**归纳前端开发要点、复盘各期任务,沉淀前端 skill 与开发约束规范;推动前端小组开发效率提升 25%、线上错误率下降 50%,连续 4 个月无 P2 级事故。
> 2. **AI 全栈转型:**借助 vibe coding 在完成前端开发任务的同时,熟悉后端业务、进行基本 CRUD 开发与后端设计,逐步转型为 AI 全栈工程师。
> 3. **i18n 双语言架构:**主导资源加工平台国际化改造…(技术细节见 `面试讲稿-智学网后端i18n改造.md`)

### ① 「开发效率提升 25%」—— 怎么做到的?

**待补充:**
- 具体靠什么提效?
  - [ ] skill 沉淀(沉淀了哪些 skill?新人上手?复用?)
  - [ ] 开发约束规范(规范了什么?代码风格 / 目录结构 / 组件规范?)
  - [ ] 复盘机制(复盘频率?产出什么?怎么反哺下次开发?)
  - [ ] 工具/脚手架(有没有搭模板 / CLI / 自动化?)
- 25% 怎么测算?(工时对比?需求交付周期?还是估算?)

**面试官可能追问:**
- "25% 这个数怎么来的?"
- "skill 和规范具体是什么?举个例子。"
- "团队几个人?你在这套机制里是什么角色?"

### ② 「线上错误率下降 50%」—— 怎么做到的?

**待补充:**
- 靠什么降的?
  - [ ] code review 机制(谁审?审什么?卡口?)
  - [ ] i18n-check 这类自研卡口脚本(简历 i18n 条提了,这里是不是同一套?)
  - [ ] 测试(单元 / 回归 / E2E?)
  - [ ] 上线流程(灰度?回滚?)
- 对比基线:错误率从 X% 降到 Y%?Bug 数量?

**面试官可能追问:**
- "50% 怎么统计的?错误率定义是什么?"
- "哪一项措施贡献最大?"
- "和 i18n-check 卡口是一回事吗?"

### ③ 「连续 4 个月无 P2 级事故」—— 质量阀门是什么?

**待补充:**
- P2 的定义(公司故障等级标准?P2 指什么程度?)
- 质量阀门具体哪些?(上线前必须过哪些检查?)
- 之前是什么情况(之前多久会有 P2?所以这 4 个月是改善后的结果?)
- "连续 4 个月"之后呢?(继续保持?还是只是某段时间?)

**面试官可能追问:**
- "P2 是怎么定义的?P1 / P2 / P3 区别?"
- "质量阀门具体是什么机制?"
- "为什么是 4 个月?之后有反复吗?"

### ④ 「基本 CRUD 开发与后端设计」—— 做了什么?

**待补充:**
- 做了哪些后端模块的 CRUD?(具体业务模块?)
- "后端设计"设计了什么?(接口设计?表结构?还是架构?)
- 技术栈?(Spring Boot? MyBatis? 还是 vibe coding 直接生成?)
- vibe coding 在这里的角色(AI 写 + 你审?还是你写 + AI 辅助?)

### ⑤ ⚠️ 层次自洽(重点):后端到底什么水平?

**问题:** "基本 CRUD"(入门)和 i18n 的"注解 + 切面 + 异常处理器 + 翻译回退"(进阶)并存,面试官会对照,问"你后端真实水平到底如何"。

**建议讲法(自洽):**
- 日常工作:用 vibe coding 承担后端 CRUD / 接口设计这类**标准需求**(广度,证明能独立做后端活)。
- 专项改造:i18n 多语言改造做到**注解 + 切面**这种相对进阶的设计(深度,证明不止 CRUD)。
- 两者关系:"日常 CRUD 是独立交付后端需求,i18n 是在负责人视角下做的专项技术方案"——**广度 + 深度互补**,不是矛盾。

**待补充:**
- [ ] "基本 CRUD" 具体到几个模块?能不能举 1-2 个例子?
- [ ] i18n 的注解 + 切面,是你设计的还是 AI 写的?(vibe coding 下你的角色:出方案 + 把关)
- [ ] 如果面试官问"你算初级 / 中级后端吗?"怎么定位自己?

## 二、武汉地大信息工程（2022.06 - 2025.07）

> 简历 bullets(2026-07-13 版):
> 1. **前端负责人全流程:**负责 3 省 5 个前端项目从 0 到 1 的全流程交付——参与设计讨论、搭建前端框架、制定开发计划,完成部署、验收与培训;探索初期 vibe coding,用 Cursor / 豆包等 agent 工具提升开发效率;多次出差现场支持交付及内网环境适配。
> 2. **驾驶舱性能优化:**通过分级加载与显示时序控制,解决十万级监测数据卡顿与三维渲染拥堵,首页加载提升约 50%、首屏从约 3.5s 优化至 1.8s。
> 3. **系统迁移与信创适配:**承接 Vue2→Vue3、.NET→Java 系统迁移中的前端改造,适配内网、麒麟、国密、UKey 等信创环境。

### ⑥ 「3 省 5 个前端项目」—— 具体哪几个?

**待补充:**
- [ ] 哪 3 个省?(简历简介提到甘肃/云南/广西/青海,5 项目落在哪 3 省?)
- [ ] 5 个项目分别是什么?(GIS 可视化?搬迁?其他业务系统?)
- [ ] 你在 5 个项目里都是负责人吗?还是部分负责?

**面试官可能追问:**
- "5 个项目分别讲一个最难的。"
- "3 省是哪三个?项目规模分别多大?"
- "5 个项目同时推进还是分期?"

### ⑦ 「探索初期 vibe coding / Cursor / 豆包」—— 怎么用的?

**待补充:**
- [ ] "初期"是哪段时间?(2023?2024?)—— 注意和讯飞"Claude Code 2026.01 起"的时间线衔接,别冲突
- [ ] Cursor 当时用来干嘛?(代码生成?重构?review?)
- [ ] 豆包用来干嘛?(和 Cursor 的区别 / 分工?)
- [ ] "探索"成果?(有没有量化提效?踩过什么坑?)

**面试官可能追问:**
- "为什么同时用 Cursor 和豆包?各自什么场景?"
- "初期探索遇到过什么问题?怎么解决的?"
- "当时团队对 AI 工具接受度怎么样?"

### ⑧ 「现场交付 + 内网适配」—— 典型困难?

**待补充:**
- [ ] 现场交付的典型困难?(内网无外网?部署环境差异?)
- [ ] 内网适配具体做了什么?(离线部署?依赖打包?npm 私服?)
- [ ] 信创环境(麒麟/国密/UKey)踩过的坑?

**面试官可能追问:**
- "内网环境没外网怎么调试?依赖怎么装?"
- "信创环境最坑的是什么?怎么绕过的?"
- "出差频率?现场一般待多久?"

### ⑨ 「驾驶舱性能优化」(硬数字:首页 50% / 首屏 3.5→1.8s)—— 怎么做到的?

**待补充:**
- [ ] 50% 怎么测算?(体积?加载时间?Lighthouse?)
- [ ] "分级加载 + 显示时序" 具体策略?(优先级怎么分?哪些先渲染?)
- [ ] 十万级监测数据卡顿怎么解决?(虚拟列表?数据聚合?WebSocket 节流?)
- [ ] 三维渲染拥堵怎么优化?(模型简化?LOD?WebGL 配置?)

**面试官可能追问:**
- "50% 这个数怎么来的?"
- "分级加载具体怎么分级的?"
- "三维这块用什么引擎(Cesium?Three.js?)?优化手段?"

### ⑩ 「系统迁移与信创适配」—— 细节?

**待补充:**
- [ ] Vue2→Vue3 迁移踩坑?(element-ui → element-plus?响应式改写?)
- [ ] .NET→Java 后端换了,前端要改什么?(接口对接?鉴权方式?)
- [ ] 国密 / UKey 适配具体?(加密算法?证书?)

**面试官可能追问:**
- "Vue2→Vue3 最大的坑是什么?"
