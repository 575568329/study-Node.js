## Claude Code 读取规则

1. 读取 `CLAUDE.md` 获取当前技能指针
2. 读取 `study-notes/{当前技能}/INDEX.md` 获取技能索引
3. 按索引中的链接按需加载具体笔记

## Obsidian 使用

- 启动 Obsidian → 打开 `study-notes` 文件夹作为 vault
- 每个技能的 `INDEX.md` 是该技能的主入口
- 使用 `[[]]` 双向链接在知识点之间跳转
