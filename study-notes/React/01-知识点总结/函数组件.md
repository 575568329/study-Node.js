# 函数组件

> 学习日期: 2026-03-31 | 置信度: 高

---

## 核心概念

React 函数组件就是**返回 JSX 的普通函数**。逻辑和 UI 在同一个函数中，不像 Vue3 分成 `<script>` + `<template>`。

## 代码示例

```tsx
// 最简组件
function Greeting({ name }: { name: string }) {
  return <h1>Hello, {name}</h1>
}

// 带状态的组件
function Counter() {
  const [count, setCount] = useState(0)
  return (
    <div>
      <p>{count}</p>
      <button onClick={() => setCount(c => c + 1)}>+1</button>
    </div>
  )
}
```

## 关键要点
1. 组件名必须大写开头（React 区分原生 HTML 标签和自定义组件）
2. 组件就是一个函数，状态变化 → 整个函数重新执行
3. 与 Vue3 的本质区别：Vue 精确追踪变化，React 整体重渲染 + diff
