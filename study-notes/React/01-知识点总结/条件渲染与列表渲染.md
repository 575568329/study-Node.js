# 条件渲染与列表渲染

> 学习日期: 2026-04-03 | 置信度: 高

---

## 核心概念

React 没有 `v-if` / `v-for` 指令，用 JS 表达式实现条件渲染和列表渲染。

### 条件渲染

在 JSX 的 `{}` 中使用表达式：

```tsx
// 三元运算符 = v-if / v-else
{isLoggedIn ? <h1>欢迎回来</h1> : <h1>请登录</h1>}

// && 短路 = v-if（没有 else）
{isLoggedIn && <p>你已登录</p>}

// 模拟 v-show（用 style 控制显示隐藏）
<p style={{ display: isVisible ? 'block' : 'none' }}>内容</p>
```

### 列表渲染

用 `.map()` 遍历数组，替代 `v-for`：

```tsx
<ul>
  {items.map((item, index) => (
    <li key={index}>{item}</li>
  ))}
</ul>
```

## 关键要点

1. `{}` 中只能放**表达式**（三元、&&、.map()），不能放 if/for 语句
2. `.map()` 必须 return JSX，箭头函数用 `()` 包裹多行
3. `key` 必须提供，**优先用唯一 ID 而非 index**
4. 条件渲染返回的是 JSX，不是 console.log

## Vue3 对比

| Vue3 | React |
|------|-------|
| `v-if` / `v-else` | 三元运算符 `? :` |
| `v-if`（无 else） | `&&` 短路 |
| `v-show` | `style={{ display: ... }}` |
| `v-for="item in list"` | `list.map(item => ...)` |

## ❌ 常见错误与纠正

### 错误1：条件渲染用 console.log
- **错误示例**: `isLoggedIn ? console.log('欢迎') : console.log('登录')`
- **错误原因**: 混淆了 JS 逻辑和 JSX 渲染，React 返回 JSX 而非执行函数
- **正确理解**: `{isLoggedIn ? <div>欢迎</div> : <div>登录</div>}`
