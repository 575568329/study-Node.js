# 数据获取模式

> 学习日期: 2026-04-04 | 置信度: 高

---

## 核心概念

React 中获取后端数据的两种方式。

### 方式1：useEffect + fetch（基础）

```tsx
useEffect(() => {
  fetch('/api/users')
    .then(res => res.json())  // 第一个then：把响应流解析成JSON
    .then(data => setUsers(data))  // 第二个then：拿到真正的数据
}, [])
```

两个 `.then` 的原因：
1. `fetch()` 返回 HTTP 响应对象（数据还在流里，不能直接用）
2. `res.json()` 把流解析成 JS 对象（这一步是异步的，所以返回 Promise）
3. 第二个 `.then` 才拿到真正的数据

### POST/PUT 传数据

```tsx
fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: '张三', age: 25 })
})
```

三步：method 指定方法，headers 声明格式，body 放数据。

### 方式2：TanStack Query（推荐）

```tsx
import { useQuery } from '@tanstack/react-query'

const { data, isLoading, isError, error, refetch } = useQuery({
  queryKey: ['users'],  // 缓存标识
  queryFn: () => fetch('/api/users').then(res => res.json())
})
```

queryKey 缓存规则：
- 所有值相同 → 用缓存，不发请求
- 任何一个不同 → 重新请求
- 例：`['users', keyword, page]` 中任一变化都会重新请求

### 加载与错误状态

```tsx
if (isLoading) return <p>加载中...</p>
if (isError) return (
  <div>
    <p>错误: {error.message}</p>
    <button onClick={() => refetch()}>重试</button>
  </div>
)
return <ul>{data.map(u => <li key={u.id}>{u.name}</li>)}</ul>
```

## 对比

| | useEffect + fetch | TanStack Query |
|---|---|---|
| 代码量 | 多（手动管理 loading/error） | 少（自动管理） |
| 缓存 | 无 | 自动缓存 |
| Vue3 等价 | Pinia action 手动管理 | @tanstack/vue-query |
