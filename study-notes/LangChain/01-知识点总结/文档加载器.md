# 文档加载器（Document Loaders）

## 核心概念

文档加载器负责**从各种数据源加载文档**，是 RAG 流程的入口。

### 为什么需要文档加载器

之前 RAG 流程中的知识库是硬编码字符串：

```javascript
// 硬编码（仅学习用途）
const knowledgeBase = '这是一段硬编码的知识库文本...'
```

文档加载器让你从**真实文件**加载知识库：

```javascript
// 从文件加载（真实项目用法）
const docs = await loader.load()
```

### 文档加载器类型

| 加载器 | 来源 | 包 |
|--------|------|-----|
| TextLoader | .txt 文本文件 | @langchain/classic |
| CSVLoader | CSV 表格 | langchain |
| PDFLoader | PDF 文档 | langchain |
| DocxLoader | Word 文档 | langchain |
| CheerioWebBaseLoader | 网页 HTML | langchain |

## TextLoader 用法

### 安装

```bash
npm install @langchain/classic
```

> **注意**：TextLoader 的导入路径已变更。旧路径 `langchain/document_loaders/fs/text` 不再可用，需从 `@langchain/classic/document_loaders/fs/text` 导入。

### 基本用法

```javascript
import { TextLoader } from '@langchain/classic/document_loaders/fs/text'

// 创建加载器，传入文件路径
const loader = new TextLoader('./knowledge.txt')

// 加载文档
const docs = await loader.load()

// docs 是数组，每个元素是一个 Document 对象
console.log(docs[0].pageContent)  // 文本内容
console.log(docs[0].metadata)     // { source: './knowledge.txt' }
```

### 在 RAG 流程中使用

```javascript
import { TextLoader } from '@langchain/classic/document_loaders/fs/text'
import { RecursiveCharacterTextSplitter } from '@langchain/textsplitters'

// 1. 加载文档
const loader = new TextLoader('./knowledge.txt')
const docs = await loader.load()

// 2. 切片
const splitter = new RecursiveCharacterTextSplitter({
  chunkSize: 200,
  chunkOverlap: 30
})
const chunks = await splitter.splitText(docs[0].pageContent)

// 3. 向量化 → 存入 Chroma → 查询 → 生成
// （后续 RAG 流程不变）
```

## Document 对象结构

```javascript
{
  pageContent: '文档的文本内容',
  metadata: {
    source: './knowledge.txt',  // 文件路径（自动填充）
    // 其他元数据取决于加载器类型
  }
}
```

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 导入路径不存在 | `langchain/document_loaders/fs/text` 已移除 | 改为 `@langchain/classic/document_loaders/fs/text` |
| 需要安装额外包 | TextLoader 已迁移到 @langchain/classic | `npm install @langchain/classic` |
| 文件路径错误 | 相对路径基于运行目录 | 使用绝对路径或确认运行目录 |
