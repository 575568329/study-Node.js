# 侧边栏差异化渲染

> Day 6（2026-05-05）

---

## 核心概念

侧边栏根据当前页面上下文显示不同的操作项和内容列表，提升用户体验和产品直觉。

## 设计方案

| 页面 | 操作按钮 | 列表内容 |
|------|---------|---------|
| 对话页 | "新对话" 按钮 | 历史对话列表 |
| 数据页 | "新建知识库" 按钮 | 知识库列表 |
| 图谱页 | 无操作按钮 | 收藏节点列表 |

## 实现要点

1. **路由感知**: 通过 Next.js 的 `usePathname()` 获取当前路径
2. **条件渲染**: 根据路径判断显示哪些操作项和列表
3. **数据持久化**: 历史对话和收藏节点使用 JSON 文件存储（db.ts 扩展）
4. **向后兼容**: 旧数据文件中不存在 conversations/favorites 字段时自动初始化为空数组

## 设计决策

- **JSON vs SQLite**: 选择 JSON 持久化
  - 理由: 面试作品集用 JSON 足够，避免 SQLite 部署复杂度
  - 体现: 合理的工程权衡思维，不过度设计

## 面试要点

- 为什么要做侧边栏差异化？（用户体验、上下文感知）
- 为什么不用 SQLite？（面试作品集场景下 JSON 足够，避免部署依赖）
