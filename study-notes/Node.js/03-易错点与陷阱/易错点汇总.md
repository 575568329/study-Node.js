## 📚 模块化相关

### ❌ 错误1: Promise状态理解错误

**错误理解**: reject()不管成功失败都返回
**正确理解**: reject()只处理失败情况

```javascript
// ❌ 错误理解
Promise.reject()  // "不管成功失败"

// ✅ 正确理解
Promise.resolve()  // 只处理成功
Promise.reject()   // 只处理失败
```

**相关笔记**: [[Promise基础]]

---

### ❌ 错误2: require()路径省略./

**错误代码**:
```javascript
const utils = require('utils');  // ❌ 会去node_modules找
```

**正确代码**:
```javascript
const utils = require('./utils');  // ✅ 当前目录的utils.js
```

**原因**: require()根据第一个字符判断模块类型

**相关笔记**: [[模块加载机制]]

---

### ❌ 错误3: async/await阻塞主线程

**错误理解**: async函数在等待时会阻塞主线程
**正确理解**: await只暂停当前async函数，不阻塞主线程

```javascript
async function test() {
  console.log('1');
  await new Promise(r => setTimeout(r, 1000));
  console.log('2');
}
test();
console.log('3');  // 输出: 1, 3, 2 (不是1, 2, 3)
```

**相关笔记**: [[async/await]]

## 🔧 npm相关

### ❌ 错误4: 版本号使用*

**错误做法**:
```json
{
  "dependencies": {
    "express": "*"  // ⚠️ 总是安装最新版，可能导致不兼容
  }
}
```

**正确做法**:
```json
{
  "dependencies": {
    "express": "^4.18.0",  // ✅ 兼容次版本
    "lodash": "~4.17.21"   // ✅ 只兼容补丁版本
  }
}
```

**相关笔记**: [[npm包管理]]

### ❌ 错误5: ESLint放dependencies

**错误做法**:
```json
{
  "dependencies": {
    "eslint": "^8.0.0"  // ❌ ESLint是开发工具
  }
}
```

**正确做法**:
```json
{
  "devDependencies": {
    "eslint": "^8.0.0"  // ✅ 放在devDependencies
  }
}
```

**原因**: ESLint在打包后不需要，生产环境不使用

## 📁 fs文件系统

### ❌ 错误6: 大文件一次性读取

**错误代码**:
```javascript
// ❌ 读取大文件会爆内存
const data = await fs.readFile('./huge-file.mp4');
```

**正确代码**:
```javascript
// ✅ 使用流处理大文件
const readStream = fs.createReadStream('./huge-file.mp4');
const writeStream = fs.createWriteStream('./copy.mp4');
readStream.pipe(writeStream);
```

**相关笔记**: [[fs流式操作]]

### ❌ 错误7: 同步API阻塞主线程

**错误代码**:
```javascript
// ❌ 在Web服务器中使用同步API
const server = http.createServer((req, res) => {
  const data = fs.readFileSync('./file.txt');  // 阻塞所有请求！
  res.end(data);
});
```

**正确代码**:
```javascript
// ✅ 使用异步API
const server = http.createServer(async (req, res) => {
  const data = await fs.readFile('./file.txt');  // 不阻塞
  res.end(data);
});
```

## 🌐 http服务器

### ❌ 错误10: POST数据处理错误

**错误代码**:
```javascript
// ❌ 以为可以直接从req获取body
const server = http.createServer((req, res) => {
  if (req.method === 'POST') {
    console.log(req.body);  // undefined!
  }
});
```

**正确代码**:
```javascript
// ✅ 需要监听data和end事件
const server = http.createServer((req, res) => {
  if (req.method === 'POST') {
    let body = '';
    req.on('data', chunk => body += chunk);
    req.on('end', () => {
      const data = JSON.parse(body);
      console.log(data);
    });
  }
});
```

**相关笔记**: [[http请求响应]]

### ❌ 错误11: 忘记调用res.end()

**错误代码**:
```javascript
// ❌ 只写数据，不结束响应
res.write('Hello');
// 忘记res.end()
```

**正确代码**:
```javascript
// ✅ 必须调用end()
res.end('Hello');  // 或 res.write() + res.end()
```

**原因**: 不调用end()，请求会一直挂起，客户端超时

---

### ❌ 错误12: 返回JSON没设置Content-Type

**错误代码**:
```javascript
// ❌ 没设置响应头
res.end(JSON.stringify({ code: 200, data: users }));
```

**正确代码**:
```javascript
// ✅ 设置JSON响应头
res.setHeader('Content-Type', 'application/json');
res.end(JSON.stringify({ code: 200, data: users }));
```

## 🔄 异步编程

### ❌ 错误13: await不在async函数里

**错误代码**:
```javascript
// ❌ SyntaxError
function test() {
  await Promise.resolve();  // 只能在async函数里用
}
```

**正确代码**:
```javascript
// ✅ 声明async函数
async function test() {
  await Promise.resolve();
}
```

---

### ❌ 错误14: 忘记try-catch

**错误代码**:
```javascript
// ❌ 没错误处理，Promise失败会unhandledRejection
async function test() {
  const data = await fs.readFile('./file.txt');
  return data;
}
```

**正确代码**:
```javascript
// ✅ 用try-catch包裹
async function test() {
  try {
    const data = await fs.readFile('./file.txt');
    return data;
  } catch (err) {
    console.error('读取失败:', err);
  }
}
```
