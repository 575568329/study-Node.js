# TS.5 类与装饰器

> 学习日期: 2026-03-30 | 置信度: 高

---

## 类的类型定义

```ts
// 完整写法
class User {
  name: string
  private age: number

  constructor(name: string, age: number) {
    this.name = name
    this.age = age
  }
}

// 简写（参数加修饰符，自动创建并赋值）
class User {
  constructor(
    public name: string,
    private age: number
  ) {}
}
```

## 访问修饰符

| 修饰符 | 类内部 | 子类 | 外部 |
|--------|--------|------|------|
| `public`（默认） | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ❌ |
| `private` | ✅ | ❌ | ❌ |

⚠️ protected 的意义就是"给子类用，不给外面用"。如果子类也不能用，就和 private 没区别了。

## 抽象类

只能被继承，不能直接实例化：

```ts
abstract class Shape {
  abstract getArea(): number    // 子类必须实现

  describe(): string {
    return `面积是${this.getArea()}`
  }
}

class Circle extends Shape {
  constructor(public radius: number) { super() }
  getArea(): number { return Math.PI * this.radius ** 2 }
}
```

## 装饰器

用 `@` 语法"贴"到类/方法上，修改或增强行为。Vue2 的 `@Component` 就是装饰器。

```ts
function Log(target: Function) {
  console.log(`类 ${target.name} 被创建了`)
}

@Log
class User {
  constructor(public name: string) {}
}
```

需在 `tsconfig.json` 开启 `experimentalDecorators`。

实际开发中更多是**使用**框架提供的装饰器，很少自己写。
