# TS.4 泛型（Generics）

> 学习日期: 2026-03-30 | 置信度: 高

---

## 基本概念

`<T>` 是类型占位符，调用时确定具体类型：

```ts
function identity<T>(value: T): T {
  return value
}

identity("hello")  // T 自动推断为 string
identity(123)      // T 自动推断为 number
```

## 泛型约束 (extends)

限制 T 的范围：

```ts
interface HasLength { length: number }

function getLength<T extends HasLength>(value: T): number {
  return value.length  // ✅ T 保证有 length
}

getLength("hello")   // ✅
getLength([1, 2, 3]) // ✅
getLength(123)       // ❌ number 没有 length
```

## 泛型接口

```ts
interface ApiResponse<T> {
  code: number
  data: T
  message: string
}

// 使用时指定 data 的类型
type UserResponse = ApiResponse<{ name: string; age: number }>
```

React 的 `useState<S>` 就是这个原理。

## 常用工具类型

```ts
interface User { name: string; age: number; email: string }

Partial<User>                    // 所有属性变可选
Pick<User, "name" | "age">      // 选取部分属性 → { name: string; age: number }
Omit<User, "email">             // 排除属性 → { name: string; age: number }
Record<string, number>          // 键值对 → { [key: string]: number }
```

组合使用：

```ts
type CreateUser = Partial<User> & { id: number }
```

## 条件类型与 infer（了解）

```ts
type IsString<T> = T extends string ? "yes" : "no"
type A = IsString<string>  // "yes"（字面量类型）

// infer 提取函数返回值类型
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never
type Result = ReturnType<(a: number) => string>  // string
```
