# v6 迁移指南

> 学习日期: 2026-04-25 | 置信度: ⭐⭐⭐

---

## 核心概念

Vercel AI SDK v6（ai@6.x）是一个重大版本更新，包含大量破坏性变化。以下是从 v4/v5 迁移到 v6 时需要关注的全部关键变化。

---

## 关键变化对照表

### useChat Hook

| v4/v5 | v6 | 说明 |
|-------|----|------|
| `handleSubmit` | `sendMessage` | 提交消息的方法改名 |
| `{ content }` | `{ text }` | sendMessage 参数名变化 |
| `handleInputChange` | 手动 `setInput` | v6 移除了便捷方法 |
| `isLoading` | `status` 状态机 | 用状态代替布尔值 |
| `msg.content` | `msg.parts` 数组 | 消息内容从字符串变为数组 |
| `error` | `error`（不变） | 错误对象保持 |
| 无 | `stop()` | 停止生成（新增） |
| `reload()` | `regenerate({ messageId })` | 重新生成签名变化 |

### 后端 API

| v4/v5 | v6 | 说明 |
|-------|----|------|
| `toTextStreamResponse()` | `toUIMessageStreamResponse()` | 协议格式变化 |
| `ai/react` | `@ai-sdk/react` | React Hook 独立包 |
| `openai()` | `createOpenAI()` + `.chat()` | 自定义 provider 新方式 |
| `maxSteps: 5` | `stopWhen: stepCountIs(5)` | 多步控制 API 变化 |

### 消息结构

```typescript
// v5 消息
interface Message {
  role: 'user' | 'assistant';
  content: string;  // 纯文本字符串
}

// v6 UIMessage
interface UIMessage {
  id: string;
  role: 'user' | 'assistant' | 'system';
  parts: Array<
    | { type: 'text'; text: string }
    | { type: 'tool-call'; toolCallId: string; toolName: string; args: Record<string, unknown> }
    | { type: 'tool-result'; toolCallId: string; toolName: string; result: unknown }
  >;
}
```

## 代码示例

### 自定义 Provider（以 GLM 为例）

```typescript
// v5 方式（已废弃）
import { openai } from '@ai-sdk/openai';
const model = openai('glm-4-flash');  // 默认走 /responses 端点，404！

// v6 方式
import { createOpenAI } from '@ai-sdk/openai';

export const glm = createOpenAI({
  baseURL: 'https://open.bigmodel.cn/api/paas/v4',
  apiKey: process.env.GLM_API_KEY!,
});

// 用 .chat() 方法走 /chat/completions 端点
const model = glm.chat('glm-4-flash');
```

### 完整 v6 聊天后端

```typescript
// app/api/chat/route.ts
import { streamText } from 'ai';
import { glm } from '@/lib/ai';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: glm.chat('glm-4-flash'),
    messages,
  });

  // v6: 必须用 toUIMessageStreamResponse()
  return result.toUIMessageStreamResponse();
}
```

---

## 关键要点

1. **先看类型定义再写代码** — v6 API 变化太大，IDE 类型提示是最好的文档
2. **`toUIMessageStreamResponse`** 是 v6 唯一推荐的流式响应格式
3. **`@ai-sdk/react`** 需要单独安装，不再是 `ai/react`
4. **自定义 provider 必须用 `.chat()` 方法**，否则默认走错误的端点
5. **`parts` 数组**统一了文本、工具调用、工具结果的消息结构

## ❌ 常见错误与纠正（复习重点）

### 错误1：用 `toTextStreamResponse` 导致页面不显示

- **错误示例**: `return result.toTextStreamResponse()`
- **错误原因**: 格式不匹配 v6 useChat 的协议
- **正确理解**: `return result.toUIMessageStreamResponse()`

### 错误2：从 `ai/react` 导入 useChat

- **错误示例**: `import { useChat } from 'ai/react'`
- **错误原因**: v6 拆分为独立包
- **正确理解**: `import { useChat } from '@ai-sdk/react'`（需要 npm install @ai-sdk/react）

### 错误3：用 `handleInputChange` 管理输入

- **错误示例**: `const { handleInputChange } = useChat()`
- **错误原因**: v6 移除了这个方法
- **正确理解**: 手动 `setInput(e.target.value)`
