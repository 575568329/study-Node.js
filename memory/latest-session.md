**学生自我总结（Day 3）**：
> public class 创建类，里面有构造方法和普通方法。构造方法和类的名字相同，new 的时候会自动调用这个构造方法，new 的时候会分配一个空间，改变当前类的指向为定义的内容，执行构造函数里面的方法。构造方法不能加 void。private 规定了 getter/setter 的访问权限。跨包引用使用 import。

**评价**：核心概念全部抓住，理解准确。
