## 2026-07-15 学习记录

**啃下 JS 最硬的一条链**：闭包 → 原型链 → new → this → call/apply/bind

**关键收获**：
- 这 5 块是环环相扣的：new 用到原型链和 call，call 属于 this 显式绑定，
  React 的 bind/useState 又串回 this 和闭包。不是孤立知识点。
- 同一个地基（JS 底层）撑着 Vue 的 ref、React 的 useState、防抖节流。

**过程中的高质量提问**（说明真在动脑）：
- debounce 里 `fn.apply(this, args)` 的 args 是什么
- Vue3 ref 到底长什么样、get/set 是不是 class 自带
- `this.handleClick.bind(this)` 是什么意思

**反复出现的习惯偏差（需持续纠正）**：
- 把"引擎/规则在背后做的事"说成"我/对象主动做的"
  （this 说成"向上找"、`__proto__`"去找"）。
- 面试要分清"发起者 vs 执行者"。

**自己总结时暴露的缺口（还没完全内化的）**：
- 原型链：漏了"作用是找属性时向上找"
- this：漏了优先级（new > call/bind > 点调用 > 默认）、漏了箭头函数

**下次预热题**：console.log、setTimeout、Promise.then 三个一起，谁先谁后？
