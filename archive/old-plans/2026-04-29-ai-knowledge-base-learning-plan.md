# AI 知识库问答系统 — 学习计划

> 日期: 2026-04-29 | 预计: 3-4 天 | 模式: 苏格拉底式教学 + 实战驱动

---

## 学习目标

通过搭建完整项目，把之前学过的 **LangChain.js + Vercel AI SDK + Next.js** 三个技能串起来，做出一个可演示的 RAG 知识库系统。

---

## Day 1: 项目初始化 + 数据层（今天）

### 学习重点：项目搭建 + Chroma 封装 + 内存数据库

| 步骤 | 内容 | 你会学到 |
|------|------|---------|
| 1.1 | `create-next-app` 创建项目，装依赖 | 项目初始化、依赖管理 |
| 1.2 | `.env.local` 配置 API Key | 环境变量管理 |
| 1.3 | 编写 `lib/chroma.ts` — Chroma 客户端封装 | 向量数据库连接、集合管理 |
| 1.4 | 编写 `lib/embedding.ts` — GLM Embedding 封装 | Embedding API 调用、批量向量化 |
| 1.5 | 编写 `lib/db.ts` — 内存数据库 | 数据建模、CRUD 操作 |

**交付物**：项目骨架 + 数据层可运行

---

## Day 2: 文档上传 + 切片向量化

### 学习重点：文件处理 + 文本切片 + 向量存储

| 步骤 | 内容 | 你会学到 |
|------|------|---------|
| 2.1 | 编写 `lib/chunker.ts` — 文档切片工具 | TextSplitter 使用、chunkSize/overlap 策略 |
| 2.2 | 编写 `/api/kb` — 知识库 CRUD | API Route 设计、请求处理 |
| 2.3 | 编写 `/api/kb/[id]/upload` — 文档上传 | FormData 处理、文件保存、切片+向量化流程 |
| 2.4 | 编写首页 `page.tsx` — 知识库列表 | 列表渲染、创建/删除交互 |

**交付物**：可以创建知识库、上传文档、查看文档列表

---

## Day 3: RAG 对话 + 来源追溯

### 学习重点：RAG Pipeline + 流式输出 + 来源展示

| 步骤 | 内容 | 你会学到 |
|------|------|---------|
| 3.1 | 编写 `/api/chat` — RAG 对话 API | similaritySearch + system prompt 注入 + streamText |
| 3.2 | 编写 `ChatPanel.tsx` — 聊天面板 | useChat 使用、消息渲染、流式展示 |
| 3.3 | 编写 `SourceBadge.tsx` — 来源追溯 | Tool Calling 返回 sources、来源标签渲染 |
| 3.4 | 编写 `/chat/[id]/page.tsx` — 对话页 | 页面整合、kbId 传递 |

**交付物**：完整的 RAG 对话功能，可以基于文档回答问题

---

## Day 4: 知识库详情页 + 样式打磨 + 测试

### 学习重点：页面整合 + UI 优化 + 端到端测试

| 步骤 | 内容 | 你会学到 |
|------|------|---------|
| 4.1 | 编写 `/kb/[id]/page.tsx` — 知识库详情 | 文档列表 + 上传组件 + 跳转聊天 |
| 4.2 | 编写 `DocUploader.tsx` — 文档上传组件 | FormData 上传、进度展示 |
| 4.3 | 全局样式打磨 | Tailwind CSS 布局、响应式、交互细节 |
| 4.4 | 端到端测试 | 完整流程：创建库 → 上传文档 → 对话 → 来源追溯 |

**交付物**：完整的 AI 知识库问答系统

- 每个步骤：我先讲解原理和语法 → 你写代码 → 我检查纠错

- 每个步骤完成后：整理 2-3 道面试题
- 每天结束时：记录进度 + 提交代码
