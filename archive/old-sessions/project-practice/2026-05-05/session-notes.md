**项目**: rag-docs-assistant（AI 知识库问答系统）
**状态**: 已完成

## 本次完成的功能

### 1. 前端 UI 优化方案设计

- **调研内容**: 图谱白底/暗底、Command Palette vs Inline Search、自动加载概览等争议点
- **参考来源**: Datawrapper（图谱配色）、Cambridge Intelligence（图可视化最佳实践）、NN/g（搜索交互模式）
- **结论**: 图谱采用白色主题（深色文字/边线）、搜索采用固定搜索栏 + 模态面板的混合模式

### 2. 侧边栏差异化渲染

- **需求**: 不同页面侧边栏显示不同的操作项
- **实现**:
  - 对话页: "新对话" 按钮 + 历史对话列表
  - 数据页: "新建知识库" 按钮
  - 图谱页: 收藏节点列表
- **意义**: 体现页面上下文感知，提升用户体验

### 3. KbCard 文档列表卡片化

- **改造**: 文件列表从简单文本升级为卡片式布局
- **文件类型图标**: 彩色图标区分文件类型
  - xlsx → 绿色
  - pdf → 红色
  - docx → 蓝色
  - txt → 灰色
  - md → 紫色
- **删除按钮**: 垃圾桶图标替代文字链接
- **反馈**: Toast 替代 alert 进行操作反馈

### 4. GraphCanvas 白色主题适配

- **改造**: 图谱画布从暗色主题切换到白色主题
- **调整项**: 背景色（白底）、文字色（深色）、边线色（灰色系）
- **原因**: 白底更符合文档阅读场景，且与整体系统风格一致

### 5. GraphPage 自动加载概览图

- **功能**: 组件挂载时自动调用 `/api/graph?mode=overview` 加载概览图谱
- **新增**: "重置概览" 按钮，一键回到全局视图
- **API**: ForceGraph2D 的 `centerAt()` + `zoom()` 方法控制视角

### 6. GraphSearch 混合搜索模式

- **交互设计**: 固定搜索栏作为常驻触发器 + `Ctrl+K` 快捷键唤起
- **结果展示**: 模态面板展示搜索结果
- **定位**: 点击结果后图谱自动定位到对应节点

### 7. JSON 持久化扩展

- **改动**: db.ts 新增 conversations（对话记录）和 favorites（收藏节点）CRUD
- **向后兼容**: 旧数据文件中不存在这两个字段时自动初始化为空数组
- **设计决策**: 选择 JSON 而非 SQLite — 面试作品集用 JSON 足够，避免部署复杂度

### 8. 图谱实体提取集成

- **功能**: 上传文档时调用 AI 实体提取器，自动识别文档中的实体和关系
- **技术方案**: glm-4-flash + structured output（结构化输出）
- **数据流**: 上传 → 切片 → 实体提取 → 写入 GraphStore → 图谱可视化
- **根因修复**: 之前图谱无数据是因为上传流程从未调用 entity-extractor.ts

### 9. ForceGraph2D API 踩坑

- **问题**: 2D 版本没有 `cameraPosition` 方法
- **正确用法**: 2D 版本用 `centerAt(x, y, ms)` + `zoom(level, ms)`
- **3D 版本**: 才用 `cameraPosition({ x, y, z })`
- **关键**: 2D 和 3D 的 API 不能混用

## 踩坑记录

### 1. react-force-graph-2d 没有 cameraPosition 方法
- **现象**: 调用 `graphRef.current.cameraPosition()` 报 TypeError
- **原因**: `cameraPosition` 是 3D 版本（react-force-graph-3d）的 API，2D 版本不支持
- **修复**: 2D 版本使用 `centerAt(x, y, ms)` 和 `zoom(level, ms)` 控制视角

### 2. CSS hidden 类可能被覆盖
- **现象**: file input 设置 Tailwind `hidden` 类后仍然可见（显示"选择文件, 未选择文件"）
- **原因**: Tailwind 的 `hidden` 类（`display: none`）可能被其他 CSS 规则覆盖
- **修复**: 改用 inline style `style={{ display: 'none' }}`，优先级更高且可靠

### 3. flex 布局高度传递断裂
- **现象**: 图谱页面画布不可见，高度为 0
- **原因**: Next.js 页面从 layout → page → component 的 `h-full` 链需要在每一层都是 flex 容器，中间任何一层断裂都会导致高度无法传递
- **修复**: 确保每一层都设置 `flex flex-col h-full`，让高度从根节点一直传递到图谱画布

### 4. 图谱无数据根因
- **现象**: 图谱页面空白，没有任何节点
- **原因**: 上传文档的流程中从未调用 `entity-extractor.ts`（AI 实体提取器），导致 graph.json 从未被创建
- **修复**: 在上传流程中集成实体提取步骤，上传文档后自动调用 AI 提取实体并写入 GraphStore
